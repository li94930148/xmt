# Changelog

## v9.1.20 - 2026-10-15

### 新增

- Creator Agent 同步任务增加服务端数据库时钟租约；异常退出后，过期 running 任务可自动结束并由新任务接管。

### 优化

- Yjs 协作更新遇到暂时性协调服务不可用或数据库写冲突时，保留原批次并退避重试；恢复后继续发送后续编辑。

### 修复

- 创作建议对无时区数据库时间按北京时间计算新鲜度；显式 UTC/offset ISO 时间继续按原时区解析。
- 分布式任务必须等当前续租请求结束后，才能确认完成或租约失效。

### 技术升级

- 新增迁移 031 `creator_sync_claim_lease`，按 `SAFE_EXPAND` 添加同步 claim 时间并为存量运行任务设置宽限期。

### 数据库变化

- `creator_sync_tasks` 新增 `claimed_at_ms`；不改写业务数据，旧运行任务获得一次新的租约宽限。

### 测试情况

- Creator 同步单飞、Yjs ACK 重试、创作建议时间范围和分布式任务租约专项回归通过；`npm run check`、`npm run build`、全仓 ESLint（0 errors/299 warnings）、版本/迁移/部署门禁、测试入口与差异格式检查通过。
- Android 仅同步 90120，未构建 APK；生产尚未部署，新 PR head 的 CI 待运行。
