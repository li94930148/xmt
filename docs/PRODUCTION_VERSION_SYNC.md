# 创作版本同步与大版本切换锁定

当“另开新版”成功时，旧版本快照会标记为 `superseded`，协作房间广播 `version:superseded`。仍在旧版本编辑的用户立即进入只读状态，并可一键进入最新版本。

后端使用请求版本号校验：若页面版本已不是当前版本，返回 `409 PRODUCTION_VERSION_SUPERSEDED`，历史版本可查看但不能继续写入。小修保存和“每个 major 仅保留最新 minor”的既有规则保持不变。

自 v3.0.4 起，普通输入、粘贴与自动保存不会自行创建新版本；仅用户明确选择“小修”或“另开新版”时变更版本。协作房间绑定稿件和版本，旧版本房间的写入被拒绝。服务端保存还会核对页面最后已持久化的正文：若其他人已先保存不同内容，返回冲突提示，避免旧页覆盖新稿。协作中的远端内容更新不会被当作本地编辑再次自动保存。
