# XMT 系统升级说明

## 当前版本

v2.13.8

## 本次升级内容

- 完成下一代浏览器登录凭据的安全传递和请求防伪适配，为后续内部验证做准备。
- 登录续期凭据不再出现在页面可读取的数据中，并支持安全轮换和主动清除。
- 登录相关记录采用完整提交或完整撤销，减少异常情况下的残留状态。
- 新能力默认关闭，并在正式生产环境保持不可用。
- 当前用户登录方式、登录有效期、权限和实时协作行为保持不变。

## 使用影响

本次升级仍属于内部迁移准备，不会切换现有登录页面、浏览器登录保存方式或用户认证流程。普通用户无需调整操作方式。

## 数据影响

本次升级不新增或修改数据库结构；现有用户和业务数据不受影响。
