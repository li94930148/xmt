# XMT 系统升级说明

## 当前版本

v2.13.11

## 本次升级内容

- 新增只读的认证迁移运行看板，管理员可以集中查看当前模式、运行指标和风险状态。
- 可以按用户 ID 查询未来是否命中灰度及具体原因，方便上线前核对范围。
- 增加刷新失败、安全校验异常和会话过期等停止条件提示。
- 补齐上线检查、观察、停止和回滚运行手册。
- 新能力仍默认使用现有登录方式，没有扩大真实用户范围。

## 使用影响

本次升级只增加管理员只读运行治理能力，不会切换现有登录页面、浏览器登录保存方式或用户认证流程。普通用户无需调整操作方式。

## 数据影响

本次升级不新增或修改数据库结构；现有用户、会话和业务数据不受影响。运行指标在服务重启后会重新统计。
