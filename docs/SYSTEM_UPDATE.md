# XMT 系统升级说明

## 当前版本

v2.13.9

## 本次升级内容

- 完成下一代 Web 登录方案的真实浏览器暗启验证，覆盖刷新页面、新开标签页和关闭后重开。
- 多个请求同时遇到登录过期时只执行一次续期，降低重复请求和异常退出风险。
- 登录续期失败或主动退出后，浏览器会完整清理临时认证状态。
- 新能力仍默认关闭，正式登录入口和生产环境均未切换。

## 使用影响

本次升级只增加内部浏览器验证能力，不会切换现有登录页面、浏览器登录保存方式或用户认证流程。普通用户无需调整操作方式。

## 数据影响

本次升级不新增或修改数据库结构；浏览器测试使用临时数据，现有用户和业务数据不受影响。
