# XMT 系统升级说明

## 当前版本

v2.13.10

## 本次升级内容

- 建立统一的登录迁移灰度控制，可按内部账号、指定账号或稳定比例控制未来测试范围。
- 增加登录、续期、退出和安全校验的运行观测数据，便于发现异常并及时停止灰度。
- 支持通过配置立即回到现有登录方式，已产生的会话记录继续保留以便审计。
- 新能力仍默认使用现有登录方式，正式登录入口和生产环境均未切换。

## 使用影响

本次升级只增加内部灰度治理和观测能力，不会切换现有登录页面、浏览器登录保存方式或用户认证流程。普通用户无需调整操作方式。

## 数据影响

本次升级不新增或修改数据库结构；现有用户、会话和业务数据不受影响。
