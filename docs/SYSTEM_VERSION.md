# XMT 系统版本

## 当前版本

v3.3.43

## 版本规则

- 工程版本以 `package.json` 为准。
- 每次升级递增一个明确版本，不跳过中间版本。
- 版本变更需同步 README、根目录 CHANGELOG、`docs/CHANGELOG.md` 与系统更新说明。

## 本版本摘要

本版本（v3.3.43）将同一选题、同一类型的桌面提醒在五分钟内合并更新，后续提醒不重复播放提示音；通知点击会校验站内路径并可直达关联业务页。消息记录、未读状态及列表不合并、不改写，无 API、权限或数据库变化。

本版本（v3.3.42）修复移动消息请求失败被显示成空列表的问题，提供重试入口；未读标记失败或离线时保留在消息页显示反馈。移动改密码表单补齐当前密码/新密码校验及提交中的防重复保护，并让成功提示保持可见。服务端规则不变。

本版本（v3.3.41）将移动消息缓存和选题、稿件、日报本机草稿按账号隔离。同一设备切换账号后不再自动恢复他人内容；旧版无账号归属的数据保留在设备上但不再自动应用。无服务端权限、API 或数据库变更。

本版本（v3.3.40）统一移动首页、选题列表/详情、创作列表及拍摄/发布列表/详情的未知状态兜底；拍摄 `pending` 显示为“计划中”，未知状态显示“状态待确认”，避免空白或原始内部枚举泄漏。Android 工程与生产端点 manifest 同步到 `3.3.40 / 30340`。没有修改权限、服务端状态机、写入规则或数据库。

本版本（v3.3.39）让移动日报清晰显示草稿、审核中、已通过、已退回和已归档状态；被退回时可直接查看审核意见，已通过或归档的日报明确为只读。权限及服务端状态规则未变。

本版本（v3.3.38）补全移动账号页文案、后期、摄像岗位的中文角色显示，并同步 Android 工程版本到 3.3.38 / 30338；权限配置未改变。

本版本（v3.3.37）修复移动选题详情权限状态刷新引起的重复加载，恢复负责人稳定编辑；创建和审核失败展示服务端具体说明并保持输入供重试。无数据库迁移，角色权限未变。

本版本（v3.3.36）移动创作详情展示由服务端计算的 `can_edit` 能力；不在数据写入范围内的 director 角色进入稿件后为只读，不再显示会被服务端拒绝的保存入口。无数据库迁移、未改变后端权限判定。

本版本（v3.3.35）修复移动日报草稿保存成功、后续提交失败时未保留服务端新版本的问题；重试使用最新版本号。无数据库迁移。

本版本（v3.3.34）补齐移动日历加载错误与创建失败恢复，异常数据不再伪装为空日历；验证事件所有权和关联选题的访问边界。无数据库迁移。

本版本（v3.3.33）补齐移动日历、灵感与关联选题之间的往返路径：首页入口可回到首页、工作入口可回到工作中心；无数据库迁移。

本版本（v3.3.32）优化灵感池和看板的手机布局；按钮及卡片操作文字在窄屏保持完整，删除灵感不依赖悬停，筛选标签不再逐字换行。无数据库迁移。

本版本（v3.3.31）修正看板进入拍摄/发布详情时流程记录 ID 与选题 ID 混淆的问题；关联记录缺失或读取失败时安全回到选题并提示。无数据库迁移。

本版本（v3.3.30）手机端创作、拍摄和发布编辑器采用轻量工具栏，桌面完整工具栏不变；发布编辑区适配手机宽度，Android 包版本同步到 3.3.30 / 30330。无数据库迁移。

本版本（v3.3.29）拍摄与发布详情适配手机宽度；选题协作动态显示中文审核结果，失去访问权限时不再显示本机旧详情。无数据库迁移。

本版本（v3.3.28）移动端选题新建/编辑和审核、日报提交与服务端权限对齐；权限确认前不恢复无权操作的本地草稿，日报加载失败时可重试且不允许误覆盖。消息批量已读逐条同步并保留部分失败状态。无数据库迁移。

本版本（v3.3.26）手机浏览器首次打开应用时采用移动导航及已有移动页面，布局在本次打开期间保持稳定；工作子页补齐导航归属与返回入口，移动端显示全局操作反馈。原生认证逻辑不变，无数据库迁移。

本版本（v3.3.25）将个人设置与系统管理分组，关于系统展示已保存的品牌信息；系统配置和备份读取失败均可重试，阻止未加载配置的默认值误保存。无数据库迁移。

本版本（v3.3.24）通知偏好需在偏好、渠道和事件配置全部读取成功后才允许保存，防止加载失败时空列表覆盖既有数据；Logo 选择仅更新本页预览，校验读取与解码并提示保存后才应用。无数据库迁移。

本版本（v3.3.16）修正共用 403 权限提示在明暗主题下的透明渐变和图标面板，改用现有语义柔和表面令牌与中性边框；权限判断和导航行为不变，无数据库迁移。

本版本（v3.3.15）统一共用确认弹窗中危险、警告和默认类型的图标面板，改用双主题语义柔和底色、中性边框与对比文字；默认图标不再使用固定品牌色。确认和取消逻辑不变，无数据库迁移。

本版本（v3.3.14）修复共用错误状态组件中失败、警告及未找到图标面板的主题底色，改用明确的双主题柔和表面和中性边框；错误信息与重试行为不变，无数据库迁移。

本版本（v3.3.13）修复组织权限页角色及启用/禁用徽标的主题底色，七类角色与两类状态均使用双主题语义柔和底色和中性边框；角色、账户状态与权限逻辑不变，无数据库迁移。

本版本（v3.3.12）修复全局成功、失败、警告和提示通知的透明底色问题；改用双主题语义柔和底色与中性边框，通知内容、类型和自动关闭时间不变，无数据库迁移。

本版本（v3.3.11）修复成就普通、稀有、史诗和传说徽标的主题底色，标签采用双主题语义柔和底色和中性边框；成就分布圆点继续保留对应强调色，筛选与成就业务逻辑不变，无数据库迁移。

本版本（v3.3.10）修复移动端选题列表与详情状态标签统一显示蓝色的问题，改为按业务阶段显示双主题语义柔和底色；待审核、已通过、已驳回、创作中、拍摄中和发布中各有区分，流程不变。v3.3.9 修复复盘和行动项状态标签透明底色；v3.3.8 修复灵感类别及“已转选题”标签透明底色；v3.3.7 修复发布详情状态标签透明底色；v3.3.6 修复成片制作详情阶段、本地编辑版和完成提示的透明底色；v3.3.5 修复选题详情阶段标签透明底色；v3.3.4 修复创作列表状态标签透明底色并新增对应令牌；v3.3.3 修复灵感库“有新评论”提示的透明背景并提升明暗主题对比度；v3.3.2 修复数据趋势周期选中态的低对比与透明背景问题，并复测编辑器批注路径。v3.3.1 修复浅色主题下编辑器批注输入框的硬编码表面与占位文字；v3.3.0 让新增选题支持本机草稿续写，大纲使用统一编辑器，选题列表在窄屏可横向浏览，当前稿件支持专注写作、按大纲补入缺失小节和来源引用。
