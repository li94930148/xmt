# XMT 系统版本

## 当前版本

v3.3.44

## 版本规则

- 工程版本以 `package.json` 为准。
- 每次升级递增一个明确版本，不跳过中间版本。
- 版本变更需同步 README、根目录 CHANGELOG、`docs/CHANGELOG.md` 与系统更新说明。

## 本版本摘要

v3.3.44：批量审核、删除如实呈现逐条成功和失败，保留失败选题供重试；选题详情的写入成功而刷新失败时准确提示“已提交”，避免把读取问题误报为写入失败。无 API、权限或数据库结构变化。

v3.3.0 系列累计更新（合并原 v3.3.1–v3.3.43）：涵盖选题本机草稿、编辑器与资料引用、内容工作流和移动办公、权限/缓存安全、通知与设置错误恢复，以及明暗主题一致性。系列阶段未进行数据库迁移。具体实现、测试证据与未验收事项见 docs/UPGRADE_PROGRESS.md。

更早版本（v3.2.0）将首页升级为角色工作台，打通灵感、选题、创作主链路。
