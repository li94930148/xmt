# XMT 系统版本

## 当前版本

v9.1.20

## 版本规则

- 工程版本以 `package.json` 为准。
- 每次升级递增一个明确版本，不跳过中间版本。
- 版本变更需同步 README、根目录 CHANGELOG、`docs/CHANGELOG.md` 与系统更新说明。

## 本版本摘要

Creator Agent 同步任务增加数据库时钟租约，过期占用可安全结束并接管；Yjs 对临时协调不可用/冲突退避重试。创作建议按北京时间解释无时区数据库时间，保留带时区 ISO 时间；分布式任务在续租完成后再报告结果。新增 SAFE_EXPAND 迁移 031；生产未部署，Android 仅同步元数据至 90120，未构建 APK。
