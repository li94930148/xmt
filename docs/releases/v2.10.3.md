# XMT v2.10.3

- 版本号：`v2.10.3`
- 更新时间：2026-07-29
- 升级类型：PATCH
- 标题：修复抖音粉丝与作品封面显示并优化数据驾驶舱

## 更新内容

- 完善粉丝采集、中文数字解析、可用性和幂等保存规则。
- 修复作品封面在 Agent 裁剪、服务端规范化和页面加载链路中的丢失。
- 限制全量同步中仅供审计的原始响应上传体积，完整保留标准化作品、指标和本地网络日志。
- 全量同步保留完整作品列表，默认抽取 3 条详情用于深度指标，避免无必要的逐条长等待。
- 移除账号健康度模块，六个核心指标调整为两行三列并适配窄屏。
- 缺失数据继续显示“暂无数据”，封面失败显示统一占位。

## 数据库与 API

- 无破坏性数据库结构变化；不复制、不删除历史数据。
- 上传协议保持兼容，新增字段为已有契约字段的正确传递。

## 风险说明

- 生产 Windows Agent 需要升级并重新同步后，历史空封面与粉丝值才会被真实数据补齐。
- 官方 API 运营调度保持关闭，OAuth 与 Webhook 不受影响。
