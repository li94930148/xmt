# XMT v2.11.0

- 版本号：`v2.11.0`
- 更新时间：2026-07-29
- 升级类型：MINOR
- 标题：Phase 2-A Topic 模块化基础落地

## 功能模块

- 新增 `api/modules/topics`，建立 Topic 的 Repository、SQLite Repository、Policy、Mapper、Service、Controller 和路由边界。
- `api/routes/topics.ts` 保留为 legacy 兼容入口，`/api/topics` 路径与响应格式不变。
- 新增 `/api/v1/topics` 路由准备，默认关闭；设置 `XMT_TOPICS_V1_ENABLED=true` 后启用，当前 Web 不切换。
- 新增 `shared/schema/topics.schema.ts`，v1 使用严格 Zod 输入契约，legacy 不启用严格校验。

## 数据库变化

- 无数据库结构变化。
- 无表、字段、索引、迁移或 ORM 变化。
- SQLite Repository 继续复用既有数据库工具和 SQL 语义。

## API 变化

- legacy 七个 Topic 接口继续存在，认证与权限中间件保持原位置。
- v1 准备相同七个路径，成功响应使用 `success/data/meta` envelope，错误响应携带领域错误码。
- v1 默认关闭，不产生新增线上流量。

## 前端变化

- 无前端调用路径变化。
- 系统更新页新增本版本说明，系统显示版本升级为 `v2.11.0`。

## 修复问题

- 本版本是兼容架构拆分，不包含历史业务问题修复。

## 风险说明

- Topic 行为依赖兼容测试持续约束；后续不能在模块迁移中顺手调整权限或状态机。
- 全仓 lint 仍有既有债务，本版本新增 Topic 文件定向 lint 已通过。
- v1 在完成更完整的权限与写接口观察前保持默认关闭。
