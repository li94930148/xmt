# XMT v2.12.0

- 版本号：`v2.12.0`
- 更新时间：2026-07-29
- 升级类型：MINOR
- 标题：Phase 2-B API Contract 标准化建设

## 功能模块

- 新增 v1 API 成功、错误、分页和错误码公共 Zod Schema。
- 新增 requestId 中间件，支持 `X-Request-ID` 透传、UUID 生成和响应头回写。
- 新增 Zod 驱动的 OpenAPI 3.0.3 生成器与 `/api/docs` Swagger UI。
- 新增 `packages/api-client` 基础骨架，包含请求、认证预留、错误解析和共享类型。

## 数据库变化

- 无数据库结构、表、字段、索引或迁移变化。
- 测试仅使用并清理系统临时 SQLite 数据库。

## API 变化

- Topic v1 使用标准 success/error envelope，分页元数据位于 `meta.page/limit/total`。
- v1 认证、权限、校验、资源不存在和状态冲突错误携带稳定公共错误码与 requestId。
- OpenAPI 首批覆盖 Topic 列表、详情、创建和更新接口。
- legacy `/api/*` 路径、响应和业务行为保持不变。

## 前端变化

- 系统更新页显示 v2.12.0 说明。
- 现有 Web 仍使用 legacy API，尚未切换到 api-client 或 Topic v1。

## 修复问题

- 消除 Topic v1 Controller 手工拼装响应和缺省 requestId 的契约不一致。
- 本版本不修复历史业务问题。

## 风险说明

- Topic v1 默认关闭，启用前仍需在非生产环境观察。
- OpenAPI 仅覆盖首批 Topic 接口，其他 legacy API 尚未获得 v1 Contract 保证。
- api-client 刷新 token 能力仅预留接口，不能视为 Refresh Token 体系已实现。
