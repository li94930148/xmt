# Creator Agent v2.13.10-agent 发布说明

## 修复范围

- Renderer 首次读取状态、运行探针和状态广播并发发生时，浏览器启动改为共享同一个 single-flight Promise。
- 同一账号、同一专用 Profile 在任意时刻只允许一个 Chrome 启动任务，避免一条成功、另一条撞 `SingletonLock` 后造成控制句柄失配。
- 保留 v2.13.9-agent 的单 Worker 封面检查、Chrome 后台驻留禁用、Profile 释放等待和脱敏错误分类。

## 安全边界

- 不删除 Profile 锁或登录资料，不读取或输出 Cookie、Token、账号标识及完整 XHR。
- 封面来源检查仍为只读、本地执行、零上传。
