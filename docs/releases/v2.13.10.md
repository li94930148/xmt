# XMT v2.13.10 发布说明

## 发布主题

Phase 2-C3-5-E1 Web Auth 灰度准入与观测体系建设。

## 灰度模型

| 模式 | 准入结果 |
| --- | --- |
| `disabled` | 关闭 Web Auth 灰度能力 |
| `legacy` | 所有用户继续使用 legacy |
| `internal` | 仅显式内部用户 ID 准入 |
| `allowlist` | 仅用户 ID 白名单准入 |
| `percentage` | 按用户 ID 稳定哈希比例准入 |

现有 v1/Web 双开关继续兼容：两者同时开启时映射为 allowlist。生产环境仍强制 legacy，不会因新配置开放 Web Auth。

## 观测指标

- `legacy_login_count`
- `v1_login_count`
- `refresh_success`
- `refresh_failed`
- `csrf_failed`
- `token_reuse_detected`
- `logout_success`
- `expired_count`

结构化事件使用 `auth.migration.login|refresh|logout|rollback`，记录 requestId、可用时的 userId、mode、outcome 和安全 reason，不记录 Access/Refresh/CSRF Token。

## 回滚方案

将统一模式切回 `legacy` 或 `disabled`，即可停止新的 v1-web 准入。回滚不删除 Session 或 Refresh 记录，保留安全审计与重放识别；legacy JWT 签发和验证继续有效。

## 数据库变化

无。未新增表、字段、索引、migration 或生产数据写入。

## 未切换范围

- 正式 `Login.tsx`、默认 `/api/auth/login`、Zustand 和持久 Token 不变。
- 生产 v1-web 仍关闭。
- legacy JWT、Socket/Yjs、Caddy 和线上 Cookie 策略不变。

## 下一步

C3-5-E2 建议接入可持久聚合的指标出口、告警阈值和灰度操作审计，并建立只读准入诊断能力；在明确实施指令前继续不切换用户。
