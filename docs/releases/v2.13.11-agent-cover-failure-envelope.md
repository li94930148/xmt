# Creator Agent v2.13.11-agent 发布说明

## 修复范围

- 封面来源 Worker 的失败摘要补齐 `source_classification` 与 `diagnostic_summary`，与成功摘要保持相同的聚合字段合同。
- `source_not_found`、`login_required` 和 `worker_failed` 不再被 Main 误判为不安全响应并降级成泛化错误。
- 保留 v2.13.10-agent 的浏览器 single-flight、Profile 互斥与单 Worker 检查链路。

## 安全边界

- 失败摘要仅包含固定错误码和计数，不包含 URL、作品 ID、账号标识、Cookie、Token 或页面内容。
- 封面来源检查仍为只读、本地执行、零上传。
