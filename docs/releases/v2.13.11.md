# XMT v2.13.11 发布说明

## 发布主题

Phase 2-C3-5-E2 Auth 灰度运行治理与上线准备。

## 灰度治理能力

- Auth Rollout Status Service 提供当前模式、启用状态、命中规则和准入原因。
- Metrics Service 按最近 60 分钟与 24 小时聚合登录、刷新、退出和失败事件。
- Audit Service 使用有界记录保存 actor、action、before、after、reason 和 created_at。
- Threshold/Risk Service 根据 Refresh 失败率、CSRF、Token reuse 和 expired 生成风险事件。

## 管理端

新增管理员只读认证迁移状态页面，展示模式、指标、风险、用户 ID 准入诊断和配置审计。页面不提供修改灰度的按钮或接口。

## API

新增 `GET /api/v1/auth-rollout/status`，使用标准响应 envelope、requestId、共享 Zod Schema 和 OpenAPI。迁移期继续接受 legacy Bearer JWT，仅 admin 可访问。

## 数据库变化

无。指标与审计当前使用进程内有界记录，不新增持久化表。

## 未切换范围

- 正式 Login 和默认 `/api/auth/login` 不变。
- 未切换管理员或扩大真实用户。
- 生产 v1-web、legacy JWT、Socket/Yjs、Caddy 和数据库结构不变。

## 下一步

E3 建议只选择少量内部普通账号进入 allowlist，并要求责任人、外部指标聚合、告警通知和回滚演练全部就绪；不要直接使用 percentage 或切换管理员。
