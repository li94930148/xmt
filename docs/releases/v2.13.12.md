# XMT v2.13.12 发布说明

## 发布主题

Phase 2-C3-5-E3 生产 Auth v1-web 受控灰度准入。

## 安全门禁

- 默认保持 legacy。
- 生产必须同时设置独立批准开关与 `allowlist` 模式。
- 仅明确的正整数用户 ID 可以准入。
- 生产 `internal` 与 `percentage` 模式强制回落 legacy。

## 兼容范围

- 正式 Login 与 `/api/auth/*` 不变。
- legacy JWT、Socket/Yjs、Caddy 与权限模型不变。
- 不使用管理员账号进行首批验证。

## 数据库变化

无数据库结构变化。生产灰度复用既有 `auth_sessions` 与 `auth_refresh_tokens`。

## 回滚

将 `XMT_AUTH_ROLLOUT_MODE` 恢复为 `legacy` 并关闭 `XMT_AUTH_ROLLOUT_APPROVED` 后重启服务。保留认证会话与审计记录。
