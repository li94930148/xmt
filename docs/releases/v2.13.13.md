# XMT v2.13.13 发布说明

## 发布主题

Phase 2-C3-6-A Auth 事件模型统一与外部指标基础。

## 统一事件

新增登录成功/失败、刷新成功/失败、退出、Session 创建/撤销、CSRF、Token reuse 和 Rollout 决策十类统一事件。每个事件使用固定字段，不允许携带 Token、密码或 Cookie 内容。

## 指标变化

指标只从 Auth Event mapper 派生，不再通过结构化日志行数统计。一次成功认证只增加一次 legacy 或 v1 登录计数；Session 和 Rollout 事件不会重复增加登录指标。

## 外部指标基础

新增 `AuthMetricsExporter` 抽象与 Memory 实现，支持 `increment`、`observe` 和 `gauge`，为 Prometheus/OpenTelemetry 预留适配边界。

## 管理诊断

认证迁移状态接口与只读页面增加最近 5 分钟窗口，并继续提供 60 分钟和 24 小时统计与安全事件数量。

## 兼容与数据

正式 Login、legacy JWT、Socket/Yjs、生产灰度和权限模型不变；无数据库结构变化，不删除旧日志。
