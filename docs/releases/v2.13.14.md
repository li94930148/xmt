# XMT v2.13.14 发布说明

## 阶段

Phase 2-C3-6-B：Auth 生产指标 Exporter 与告警基础建设。

## 新增能力

- 新增可组合 Auth Metrics Registry，同时支持 Memory、Prometheus 和 OpenTelemetry 适配。
- Prometheus 输出登录、Refresh、失败、Logout、安全事件、活跃 Session 与 Refresh 耗时标准指标。
- OpenTelemetry 使用厂商无关 Meter 适配接口，不绑定具体采集平台。
- Rollout 只读诊断增加 Exporter 状态、指标来源、最近事件与最近导出时间。
- 新增 Auth 告警规则，覆盖 Refresh 失败率、Token reuse、CSRF 与 Expired 异常。

## 兼容与边界

- Auth Event 仍是指标唯一事实来源，多 Exporter 只扇出同一事实，不重复计数。
- 无数据库变化；未修改 Login、legacy JWT、Socket/Yjs 或生产灰度配置。
- Prometheus Exporter 已进入默认 Registry；OTel 需由部署环境注入兼容 Meter 后启用。
- 正式 Login 准入前仍需配置外部采集、告警接收和值班验证。
