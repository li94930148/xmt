# XMT v2.13.15 发布说明

## 阶段

Phase 2-C3-6-C：Auth 生产观测链路接入与正式 Login 准入设计。

## 完成内容

- 新增默认关闭的 `/internal/metrics/auth` Prometheus 文本端点，支持监控网段 CIDR 控制。
- Prometheus 与 OpenTelemetry 指标增加稳定 `instance` 标签。
- 新增 Prometheus scrape、OTel Collector 和 Warning/Critical 告警规则配置样例。
- 新增多实例指标治理说明，明确 `active_sessions` 不可简单求和。
- 新增正式 Login 迁移计划，冻结前置条件、allowlist 步骤、回滚和 Socket/Yjs 风险。

## 安全与兼容

- Endpoint 默认关闭；公网 Caddy 示例明确返回 404，Prometheus 只从私网 Node 地址抓取。
- 指标不包含用户、Session、IP、Token、密码、Cookie 或 requestId 标签。
- 无数据库变化，正式 Login、legacy JWT、Socket/Yjs 和生产用户均未切换。
- OTel 通过模拟 Collector Meter 完成代码契约验证；真实 Collector、通知平台和生产抓取仍需部署侧联通。
