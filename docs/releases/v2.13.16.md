# XMT v2.13.16 发布说明

## 阶段

Phase 2-C3-7-A：Socket/Yjs Auth Bridge 设计。

## 完成内容

- 审计当前 Socket handshake、legacy Token、用户复查、Room 恢复和 Yjs 依赖。
- 冻结 `SocketAuthContext`、显式 legacy/v1 分支和禁止 Refresh Token 进入 Socket 的契约。
- 设计 Access 临期 Refresh、重新 handshake、Room 幂等恢复和 Yjs 状态恢复流程。
- 规划 Legacy Socket → Bridge → v1 Socket 的可回滚迁移阶段。
- 新增 Socket/Yjs Auth 测试计划，覆盖到期、断网、多标签、状态冲突和回滚。

## 兼容边界

- 本版本只增加设计文档，不修改生产 Socket、Yjs 协议、正式 Login、数据库或灰度配置。
- 当前生产 Socket 继续只接受 legacy JWT。
- 下一阶段实施前必须优先绑定 collaboration presence 与认证身份，并补齐 Room 权限判断。
