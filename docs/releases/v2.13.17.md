# XMT v2.13.17 发布说明

## 阶段

Phase 2-C3-7-B：Socket Auth Bridge 基础设施实施。

## 新增能力

- 新增 `api/modules/auth/socket/`，提供 SocketAuthContext、Zod Schema、mapper、service、错误和 middleware。
- Feature Flag `XMT_SOCKET_AUTH_BRIDGE_ENABLED` 默认关闭，生产环境硬性保持关闭。
- legacy 分支继续使用原 JWT、用户查询和 enabled 检查；v1-web 分支使用 v1 Access Token、ACTIVE Session 和用户复查。
- 禁止 legacy/v1 认证分支互相 fallback，避免 token confusion。
- Collaboration JOIN 使用服务端认证身份覆盖客户端 user payload，保留现有事件和 Yjs 协议。
- 预留 `authorizeSocketRoomJoin()` 权限入口，本阶段不改变现有业务权限规则。

## 兼容边界

- 认证 middleware 已接入现有 Socket 初始化，但默认 Flag 关闭时保持 legacy 行为。
- 未修改正式 Login、`/api/auth/login`、数据库、Yjs wire event、Caddy 或生产灰度。
