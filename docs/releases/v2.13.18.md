# XMT v2.13.18 发布说明

## 阶段

Phase 2-C3-7-C：Socket Coordinator + Yjs Recovery Bridge 实施。

## 新增能力

- 新增 `src/auth/socket/`，提供 Socket 生命周期状态、Token Provider 和 Coordinator。
- Access Token 临期时由 Auth Runtime 执行单飞 Refresh；Coordinator 只负责更新 handshake token 并重建连接。
- 新增 Room 恢复编排，顺序固定为 JOIN、Yjs、Awareness、typing、lock。
- 新增 Yjs Recovery Bridge 和 Provider 冻结/恢复边界，保留同一 `Y.Doc`，不修改现有协作 wire event。
- logout/session revoke 会进入 `expired` 并清理 Socket Coordinator 状态。

## 兼容边界

- 未接入正式 Login、现有 `useSocket` 或生产 Web Auth；legacy Socket 默认行为保持不变。
- 未修改数据库、JWT、Socket/Yjs 协议、Caddy 或生产配置。
- Refresh Token 不进入 Socket，也不进入日志、指标或恢复状态。
