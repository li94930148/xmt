# XMT v2.13.19 发布说明

## 阶段

Phase 2-C3-7-D：Socket Coordinator 受控接入与真实浏览器一致性验证。

## 新增能力

- 新增默认关闭的 `VITE_XMT_SOCKET_COORDINATOR_ENABLED`。
- Auth Runtime 存在且开关开启时，Coordinator 接管受控 Socket 创建、Token 临期刷新和重连。
- 新增只传递 `auth_changed`、`token_refreshed`、`logout` 的 BroadcastChannel 多标签协调。
- 新增 `AUTH_EXPIRED`、`SESSION_REVOKED`、`USER_DISABLED` 标准 Socket 生命周期原因。
- 新增 Playwright 浏览器恢复契约测试。

## 兼容边界

- legacy 默认登录、legacy Socket、Yjs wire event、数据库和生产配置均未改变。
- Access Token 与 Refresh Token 不进入 BroadcastChannel。
- 本机浏览器执行环境不可用时，浏览器测试只报告跳过原因，不将其标记为通过。
