# XMT v2.13.2

- 版本号：`v2.13.2`
- 更新时间：2026-07-30
- 升级类型：PATCH
- 标题：Phase 2-C2 Auth Module 边界落地

## 代码变化

- 新增 `api/modules/auth`，分离 Repository、Service、Controller、Token、Password、Mapper、类型与 Schema 边界。
- legacy `POST /api/auth/login` 保留原路径，通过兼容路由委托 Auth Module。
- `api/utils/jwt.ts` 保留兼容导出，HTTP middleware 和 Socket 不需要修改导入路径。
- 新增 `npm run test:auth` 行为冻结测试。

## 行为兼容

- 登录请求、成功响应、错误状态码和中文消息保持不变。
- JWT payload 仍为 `userId`、`username`、`role`，有效期仍为 7 天。
- 登录成功仍写入相同 `activity_log` 记录。
- authenticate 仍回查数据库用户状态与当前角色。
- logout 仍不撤销已签发 JWT；本版本只冻结现状，不修复该历史行为。

## 数据库变化

- 无数据库结构、表、字段、索引、数据或迁移变化。
- 未创建 `refresh_tokens` 表。
- 测试使用系统临时目录中的 SQLite 数据库并在完成后清理。

## 未包含内容

- 未引入 Refresh Token、设备会话或主动撤销。
- 未修改 RBAC、双轨角色模型、Socket 认证或前端 Login 流程。
- 未调整密码算法、JWT payload、签名方式或有效期。

## 风险说明

- Auth Module 当前只接管登录；`me`、`change-password` 和 logout 保留在 legacy route，等待后续独立兼容迁移。
- 7 天 JWT 无服务端撤销及 logout 后仍有效的风险继续存在。
- 下一阶段涉及数据库会话模型前，必须先评审 `session_id/family_id`、轮换事务和回滚方案。
