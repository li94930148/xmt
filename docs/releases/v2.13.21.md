# XMT v2.13.21 发布说明

## 阶段

Phase 2-C3-8-B1：正式 Login 双轨灰度准入设计与实施准备。

## 新增能力

- 新增 Login Rollout Policy，统一定义 legacy/v1-web 双轨准入。
- 新增 `XMT_LOGIN_ROLLOUT_ENABLED=false`，默认不改变正式登录。
- 增加管理员保护、percentage 审批门禁和生产回滚决策。

## 兼容边界

- 未修改 `/api/auth/login`、legacy JWT、数据库、Socket/Yjs 或生产配置。
- 本阶段只提供策略与实施准备，不自动切换用户、不自动扩大灰度。
