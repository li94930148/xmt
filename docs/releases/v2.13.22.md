# XMT v2.13.22 发布说明

## 阶段

Phase 2-C3-8-B2：Login Gateway 双轨接入与内部账号灰度准备。

## 新增能力

- `/api/auth/login` 接入默认关闭的 Login Gateway。
- allowlist 普通用户可进入已有 v1-web Auth 适配器；其余登录保留 legacy。
- v1 adapter 缺失时安全回退 legacy。

## 兼容边界

- legacy JWT payload、7 天有效期、错误提示、限流和 activity_log 未改变。
- 未启用 percentage、未自动扩大 allowlist、未修改数据库、Socket/Yjs 或生产配置。
