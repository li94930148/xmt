# XMT v2.13.3

- 版本号：`v2.13.3`
- 更新时间：2026-07-30
- 升级类型：PATCH
- 标题：Phase 2-C2.5 Auth 完整收口

## 代码变化

- legacy `GET /api/auth/me`、`POST /api/auth/change-password` 和 `POST /api/auth/logout` 通过 Auth Module 路由进入 Controller、Service 与 Repository。
- Repository 增加按用户 ID 查询、密码更新、强制改密标记清除和活动日志能力。
- Password Service 增加与既有 bcrypt cost 一致的 hash 能力。
- `api/routes/auth.ts` 收敛为 Auth Module legacy router 的兼容导出。
- Auth 行为冻结测试覆盖 me、change-password、logout 和完整认证链路。

## 行为兼容

- 所有接口继续使用 `/api/auth/*` 和 legacy 裸响应，不使用 v1 envelope。
- `/me` 继续通过 authenticate 回查数据库，不直接信任 JWT 中的角色或用户状态。
- 修改密码仍校验旧密码、新密码至少 6 位、使用 bcrypt cost 10、清除 `force_change_password` 并写活动日志。
- logout 仍只返回成功，不撤销 JWT；修改密码后既有 JWT 也仍有效。
- JWT payload 和 7 天有效期、前端 token 存储、Socket 认证、RBAC 和权限模型均未改变。

## 数据库变化

- 无数据库结构、表、字段、索引、初始化逻辑、迁移脚本或业务数据变化。
- 未创建 refresh token 或 session 表。

## 风险说明

- 7 天 JWT 无主动撤销和 logout 后仍有效是本阶段明确冻结的历史行为，不是新增能力。
- 密码修改的历史流程由多个顺序数据库操作组成，本阶段保持现有业务结果，未扩展为会话安全治理。
- Refresh Token、设备会话和 Socket token 续期必须等待 Phase 2-C3 指令。
