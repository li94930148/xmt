# XMT v2.13.4 发布说明

## 发布主题

Phase 2-C3-2 Auth Session 数据库基础设施建设。

## 主要变化

1. 新增 `auth_sessions`，作为未来多设备登录会话的稳定记录。
2. 新增 `auth_refresh_tokens`，只保存未来 Refresh Token 的 hash 与轮换关系，不保存明文。
3. 新增会话与轮换记录的必要唯一索引、查询索引、到期清理索引和外键。
4. 新增独立 Session Repository 基础接口与 SQLite 实现，但未接入 Auth Service。
5. 新增 migration 专项测试，验证幂等执行、表、字段、索引、外键和既有用户数据完整性。

## 兼容性

- legacy `/api/auth/login`、`/me`、`/change-password`、`/logout` 完全保持现有行为。
- JWT payload 和 7 天有效期不变。
- 不签发 Refresh Token，不开放 `/api/v1/auth/*`。
- 前端 token 存储和 Socket 认证不变。

## 数据库变化

- 新增 `auth_sessions`。
- 新增 `auth_refresh_tokens`。
- 未修改 `users` 和其他已有表结构；migration 不回填或改写现有用户数据。

## 回滚边界

两张新表当前没有生产业务读写。若后续需停止该能力，应先停止未来接入并保留表和迁移记录；不在紧急回滚中执行破坏性删表。
