# XMT v2.13.5 发布说明

## 发布主题

Phase 2-C3-3 Auth Session 运行时服务建设。

## 主要变化

1. 新增 Session Service，负责创建会话、判断有效/过期/撤销状态，以及单会话和用户会话撤销。
2. 新增 Refresh Token Service，使用 256-bit 安全随机值和分版本 HMAC-SHA256；数据库只保存 hash。
3. 新增原子轮换能力，在一个 SQLite 写事务内完成旧 token 校验、单次消费、替换记录创建和 session 活动更新。
4. 已使用 token 再次出现时生成内部安全事件，并撤销所属 session 和 token 链。
5. Token Service 增加独立 v1 Access Token 方法，支持 `sub`、`sid`、`jti`、`type`、`iss`、`aud`、`iat` 和 `exp`。

## 兼容性

- legacy `/api/auth/*` 未接入新增服务。
- 旧 `signToken()`、`verifyToken()`、JWT payload 和 7 天有效期完全不变。
- 不开放 `/api/v1/auth/*`，不向任何客户端返回 Refresh Token。
- 前端 token 存储和 Socket 认证不变。

## 数据库变化

无新增表、字段或 migration。运行时内核复用 `v2.13.4` 的 `auth_sessions` 和 `auth_refresh_tokens`。

## 安全边界

- Refresh Token 原文不写数据库、不写日志。
- Service 返回值是内部能力，不经过 Controller 或 HTTP 响应。
- 完整 refresh 流程只有在后续 v1 暗启、契约和安全门禁完成后才能接入。
