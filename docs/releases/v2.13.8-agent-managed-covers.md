# Creator Agent v2.13.8-agent 发布说明

对应系统版本 `v2.20.19`。

## 变更

- 监听专用认证浏览器已经成功加载的图片响应，以去除查询参数后的来源身份关联作品封面。
- 只把通过 MIME、图片魔数、SHA-256、单图 128 KiB 和单次 4 MiB 上限的图片字节加入常规加密作品包。
- 官方导出继续使用独立持久化队列，同时常规作品与封面包不再被官方导出分支跳过。

## 安全边界

不上传 Cookie、Token、请求头、完整 URL、完整 XHR 或浏览器存储。无法关联、无明确 Content-Length、超限或校验失败的图片会被跳过，原同步任务继续执行并由生产端使用外链回退或占位。
