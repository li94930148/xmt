# Creator Agent v2.13.9-agent 发布说明

## 修复范围

- macOS 封面来源检查不再先启动 Chrome 做一次登录预检、关闭后又立刻让 Collector Worker 重复启动同一 Profile。
- Agent 管理的 Chrome 会话加入 `--disable-background-mode`，并在关闭上下文后等待 Profile 锁释放，避免后台进程继续占用 `SingletonLock`。
- Worker 仍只返回脱敏聚合诊断；登录失效、安全门禁、Profile 忙碌和运行时缺失分别显示固定提示。

## 安全边界

- 不删除 `SingletonLock`，不清理浏览器 Profile，也不复制或输出 Cookie、Token、账号标识和完整 XHR。
- 封面来源检查继续保持只读、仅本地、零上传，不写入生产数据或本地作品库。
