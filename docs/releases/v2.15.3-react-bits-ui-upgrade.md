# XMT V2.15.3 React Bits UI体验升级

## 升级背景

XMT 已具备完整的新媒体内容生产链路。本次升级聚焦统一前端体验，让驾驶舱、状态反馈和页面切换更一致，同时保留现有组件体系与业务权限边界。

## 升级目标

- 建立 XMT 自有 Design System，React Bits 仅作为组件动效灵感来源。
- 提升首页 Dashboard 的数据阅读效率和企业级 SaaS 质感。
- 为空状态、加载状态、弹窗和 Sidebar 提供一致的轻量动效。
- 动画使用 transform、opacity 与 CSS transition，控制在 300ms 内并尊重 reduced motion。

## 新增组件

- `src/design-system/tokens/XMTTheme.ts`
- `src/design-system/animations/useCountUp.ts`
- `src/design-system/components/AnimatedNumber.tsx`
- `src/design-system/components/ProgressBar.tsx`
- `src/design-system/components/XMTCard.tsx`

## 页面变化

- 首页核心指标支持数字变化动画；完成率增加进度条趋势展示。
- 主要页面通过既有 `AnimatedPage` 统一过渡。
- 选题、作品、意见箱及数据页面复用的 EmptyState 增加微动画与操作引导。
- 列表与详情页面复用的 LoadingState 继续沿用骨架屏，并统一展示节奏。
- FormModal、ConfirmModal 增加进入动效；Sidebar 增加展开收缩动画。

## 性能影响

动画主要使用 CSS transform、opacity、width transition；数字动画只在指标挂载或数据变化时运行一次，不使用持续 JS 循环。生产构建后应继续关注 chunk 与首屏加载体积。

## 兼容性

React 18、TypeScript、Tailwind CSS、现有路由、权限过滤、API、数据库、Workflow Engine、Socket.IO、Yjs 与 Creator Agent 均保持兼容。
