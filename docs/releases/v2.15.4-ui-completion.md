# XMT V2.15.4 React Bits UI应用补全

## 升级背景

V2.15.3 已建立 XMT Design System，但 XMTCard 尚未接入实际业务页面。本版本完成组件应用补全，确保 React Bits 风格卡片能力真正覆盖主要工作页面。

## 应用范围

- Dashboard：数据卡片迁移至 XMTCard，保留 AnimatedNumber、ProgressBar 和原有数据逻辑。
- Topics：顶部统计卡与核心列表容器迁移至 XMTCard，保留表格语义、筛选、分页和权限逻辑。
- Workflow：模板卡、节点展示卡和流程预览卡迁移至 XMTCard，保留权限和状态机。
- Creator：复用的 Creator MetricCard 迁移至 XMTCard，保留数据加载与展示逻辑。

## 兼容性

本次仅修改前端组件组合，不修改 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。

- `npm run build`
