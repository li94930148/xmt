# XMT V2.16.0 React Bits原生体验升级

## 一、升级背景

V2.15.x 完成了 XMT 自研 Design System 的基础建设，统一了视觉 token、基础卡片、指标、进度和常用交互动效。

V2.16.0 在保留 XMT Design System 的基础上，正式接入 React Bits 官方组件，将高辨识度视觉体验应用到登录、驾驶舱、重点选题和创作者账号等关键页面。

## 二、技术实现

- React Bits 组件采用官方 TypeScript + Tailwind 源码接入方式，并保留来源注释。
- 官方组件统一放置于 `src/components/reactbits`，作为第三方组件层。
- XMT 业务适配组件统一放置于 `src/components/xmt-ui`，负责真实数据映射、业务语义、响应式约束和降级策略。
- 页面通过 XMT 业务适配层使用 React Bits，避免页面直接大量依赖第三方组件实现。
- Aurora 使用 OGL 渲染，并提供 WebGL 不可用时的静态渐变 fallback。

## 三、组件列表

- AuroraBackground
- MagicBento
- AnimatedContent
- SpotlightCard
- ProfileCard

## 四、页面变化

### Login

接入 Aurora 动态背景，增强登录页视觉层次；WebGL 不可用时自动使用静态渐变背景。

### Home

接入 MagicBento 驾驶舱布局，强化核心数据与业务入口的分组关系。

### Dashboard

核心数据展示接入 AnimatedContent，保留原有指标计算和数据逻辑。

### Topics

热门、推荐及重点选题使用 SpotlightCard，提供轻量 hover 光效与聚焦反馈；普通选题列表保持原有展示方式。

### Creator

Creator Dashboard 接入 ProfileCard，展示已同步的头像、名称、UID、账号状态及内容数据，不新增不存在的业务指标。

## 五、兼容性

- 后端 API 无变化。
- 数据库无变化。
- 权限系统无变化。
- Workflow 与 Workflow Engine 无变化。
- Socket.IO 与 Yjs 无变化。
- 保持 React 18、TypeScript 5.8、Tailwind CSS 3.4 与 Vite 6 技术栈。

## 验收范围

- Login：Aurora 动态背景与 WebGL fallback。
- Home / Dashboard：MagicBento 与 AnimatedContent。
- Topics：SpotlightCard 真实渲染和详情导航。
- Creator：ProfileCard 真实数据展示和作品库导航。
- 视口：1440 桌面端、390×844 移动端。
