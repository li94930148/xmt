# XMT V2.16.1 首页驾驶舱视觉增强

## 一、升级目标

V2.16.1 在 V2.16.0 React Bits 原生组件集成基础上，进一步强化 Home 的产品展示入口属性，将普通后台首页升级为具有品牌辨识度的内容生产驾驶舱。

## 二、视觉升级

- 新增融合 Aurora 动态背景的品牌 Hero，展示平台名称、“内容生产驾驶舱”标题、核心指标与主要业务入口。
- MagicBento 使用非对称布局，以内容生产指数作为主视觉大卡，并配置今日任务、新增选题、待审核、发布数据、播放表现和 AI 能力入口。
- 首页关键内容通过 AnimatedContent 分层进入，增强数字、趋势信息和卡片的首屏节奏。
- 启用 MagicBento 的 Spotlight、边框光效、粒子、3D 倾斜、磁吸与点击反馈。

## 三、组件关系

页面继续遵循以下组件架构：

`React Bits 官方组件 → XMT 业务适配层 → Home 页面`

- React Bits 第三方组件层：`src/components/reactbits`
- XMT 业务适配层：`src/components/xmt-ui`
- 页面入口：`src/pages/Home.tsx`

## 四、兼容与降级

- 保持 React 18、TypeScript 5.8、Tailwind CSS 3.4 与 Vite 6。
- WebGL 不可用时使用静态渐变背景。
- 用户启用减少动态效果偏好时停止 Aurora 动态渲染。
- 移动端自动切换为单列卡片布局，保留核心品牌视觉且不产生横向滚动。

## 五、影响范围

- 保持 V2.16.0 已有 Aurora、MagicBento、AnimatedContent、SpotlightCard 和 ProfileCard。
- 不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。
- 首页所有指标继续使用现有真实数据与权限结果，不新增虚构业务字段。

## 六、验收范围

- 1440 桌面端：首页 Hero、Aurora、非对称 Bento、主指标大卡及高级交互。
- 390×844 移动端：无横向溢出、卡片自动适配、页面滚动正常。
- 工程检查：`npm run check`、`npm run build`、`npm run version:check`、`git diff --check`。
