# XMT V2.17.0 React Bits 原生动效主题系统

发布日期：2026-08-08

## 升级内容

- 将 React Bits 官方 TS + Tailwind Registry 源码扩展为可审计的官方组件层。
- 建立 `src/features/reactbits-appearance` 外观选择层和独立 Zustand 本地配置 Store。
- 提供岚曜极光、深空科技、丝绸创意、线性协作、极简无扰、自由搭配六套预设。
- 支持实时预览、导入导出、恢复默认、reduced-motion、移动端降级和 WebGL 静态 fallback。

## 兼容性

不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO 或 Yjs。Silk 使用与 React 18 兼容的 `@react-three/fiber@8.17.14`，不修改官方视觉逻辑。
