# XMT V2.17.1 React Bits 浅色主题与字体兼容修复

发布日期：2026-08-08

## 修复内容

- 保持 React Bits 官方源码不变，在 `src/features/reactbits-appearance` 业务适配层修复按钮主题和尺寸兼容。
- SpecularButton 根据明暗主题与按钮变体传入颜色参数；GlareHover、ClickSpark、Magnet 使用紧凑的 inline 包装，避免 500px 容器和整行拉伸。
- 文本动画增加语义字号、行高和外层安全空间；TrueFocus 仅限品牌或 AI 标题，窄屏自动回退为静态文本。
- 用户字号只作用于业务正文，保留 16px 浏览器根字号以及 React Bits、Tailwind、图标和布局尺寸稳定性。
- 外观中心同时显示深色和浅色真实预览；开发环境提供完整的按钮兼容矩阵。

## 兼容性

不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO 或 Yjs；React Bits 官方组件的核心动画源码保持不变。
