# XMT V2.18.0 React Bits 场景化视觉编排升级

发布日期：2026-08-12

## 发布摘要

V2.18.0 完成 React Bits 场景化视觉编排与全系统体验升级，重点收口 Settings Center / Appearance Center，并完成 Home、Topics、Daily Report、Creator、Analytics、Workflow 与 Editor 的场景化验收。

## 主要内容

- 建立 React Bits 官方组件 → Typed Adapter → Semantic Slot → Page Scene 的统一视觉架构。
- 提供六套视觉方案：岚曜极光、深空科技、丝绸创意、线性协作、极简无扰、自由搭配。
- Appearance Center 支持页面应用范围、motionMode、深浅主题、界面字号、高级设置、Scene Preview、import/export/reset 与配置持久化。
- 完善表单 accessible name、preset `aria-pressed` 与高级设置折叠语义。
- 优化 Silk / Fiber 8 生命周期兼容，确保关闭动效、路由切换和 reload 后不残留背景 Canvas。
- Editor 使用轻量 Scene 外壳，保持编辑、选区、保存与协作逻辑不变。
- Workflow 完成视觉升级，strict control 与 Workflow Engine 判定逻辑保持不变。

## 验证

- 完成桌面、平板、移动端视口回归。
- 完成 Persistent-Off、Guard-Only、Canvas owner/lifecycle、配置恢复与错误门禁验证。
- `npm run check`、`npm run build` 与 `git diff --check` 通过。

## 业务边界

Workflow Engine、Backend、API、permissions、Socket.IO、Yjs 与 Database 未修改。本版本不包含生产部署。
