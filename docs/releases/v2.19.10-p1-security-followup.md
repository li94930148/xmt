# XMT v2.19.10 P1 安全补充

- 版本：v2.19.10
- 类型：PATCH 安全补充
- 背景：v2.19.9 的 PR #22 在两项 P1 review 修复提交进入 PR 前已被合并，因此本版本用于完成安全补丁闭环。

## 修复

1. Legacy 401 Recovery 使用精确 URL Origin，防止新 Bearer Token 发往伪同源、错误端口或 HTTP 降级地址。
2. `/api/roles/user/:userId` 纳入统一角色授予上限，并在事务前完整校验多角色请求。
3. 角色创建和修改的 `permission_ids` 纳入调用者当前有效权限 ceiling，避免修改自身角色后自举提权。
4. 增加对应回归测试，并将角色管理安全测试加入核心安全 CI 门禁。

## 安全影响

- 无 DB schema migration。
- 无生产配置修改。
- 无 Creator Agent protocol 修改。
- 本版本未部署生产；在合并前不得部署含已知 P1 缺口的 v2.19.9。
