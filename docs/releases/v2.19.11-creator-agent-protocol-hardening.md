# XMT v2.19.11 Creator Agent 上传协议安全收口

- 版本：v2.19.11
- 日期：2026-08-20
- 类型：PATCH 安全修复

## 背景

现行 `/api/creator-agent/data-sync` V1 已具有 timestamp、nonce、HMAC-SHA256 与 AES-GCM 防护。本次代码复核发现 legacy protocol fallback 和旧 `/report` 上传入口仍可能绕开 timestamp/nonce 防重放边界。

## 修复

- `/data-sync` 永久要求 `protocol_version=1`，不再依赖 runtime flag。
- HMAC 按明确字段顺序覆盖 protocol、Agent 绑定、timestamp、nonce、采集时间和密文数据；仅在 timestamp、严格 UUID nonce 与签名通过后原子预留 `(agent_id, nonce)`。
- 旧 `POST /api/creator-agent/report` 无现行客户端调用，已安全退役并返回 410，提示升级至 `/data-sync`。

## 验证

- 覆盖 V1、时间窗、非法 nonce、签名篡改、nonce poison、重复与并发重放、跨 Agent nonce 和业务副作用。
- 新合同纳入 `core-security-contract`。

## Migration

None。复用既有 `creator_agent_nonces` 表；无生产数据迁移，无 Creator 业务数据删除。

## Agent

Agent runtime/client 未修改，保持 `2.11.0-agent`。

## Production

Not deployed。
