# XMT v2.19.8 Android Production Endpoint Build Contract

## 版本与范围

- 版本：v2.19.8
- 类型：PATCH 修复
- 范围：Android 生产构建端点合同、Native fail-closed、APK 产物校验。

## 修复

clean worktree 以前会构建出未注入端点的 Android APK。Capacitor WebView 的 `https://localhost` 会把 relative `/api` 解析为本地应用资源，返回 HTML 200 而不是真实生产 API。

本版本提供确定性 `mobile:*:production` 命令：固定打入公开、非敏感的 `https://lanyaomedia.com/api` 和 `https://lanyaomedia.com`，并生成随 dist、Capacitor assets、APK 打包的 `xmt-mobile-build.json`。

Native Production 缺失、relative、localhost、局域网或 HTTP endpoint 会 fail-closed；移动 API Health 与认证 JSON 读取拒绝 HTML 200 假成功。

## 兼容与安全边界

- Web Development / Production 继续使用 same-origin `/api`。
- 不改变 RBAC、Auth Session、Native Refresh Scheduler、Socket/Yjs 权限或 CORS allowlist。
- 不包含 token、密码、cookie、keystore 或任何 secret。
- Production Mobile Auth / Socket allowlist 默认保持关闭。
