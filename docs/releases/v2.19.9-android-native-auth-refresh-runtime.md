# XMT v2.19.9 Android Native Auth 真实续期调度

- 日期：2026-08-17
- 类型：PATCH 修复
- 范围：Android Native Auth Runtime

## 修复

服务端 V1 Login/Refresh 的 `expiresIn` 现在被验证并完整传递到 Android Native Runtime。真实登录和每次 refresh 都显式建立下一次 lifetime scheduler；JWT `exp` 只作为诊断性回退。

## 安全与验证

调度 trace 不包含 Token、Refresh Credential、Cookie 或 Authorization。新增双周期刷新、延迟 timer、Resume/Network single-flight 与 cleanup 集成测试。Android Production Endpoint Contract、RBAC、会话并发和 900 秒服务端 TTL 保持不变。
