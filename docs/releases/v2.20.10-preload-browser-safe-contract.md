# XMT v2.20.10 Creator Agent Preload 浏览器安全契约

- System：`v2.20.10`
- Creator Agent：`v2.13.5-agent`

## 修复范围

正式包中的 sandboxed Preload 曾经通过 Renderer 状态契约间接运行时导入 `node:crypto`，使 contextBridge 未建立并导致 Renderer 空白。本版本将设备键控 HMAC、真实 `AgentConfig` 和绑定身份投影固定在 Main-only 模块；Preload 与 Renderer 仅导入不含 Node builtin 的白名单契约。

若预期 Bridge 不存在，Renderer 只显示固定脱敏提示“安全接口加载失败，请退出并重新安装 Creator Agent。”，不回退至同步、旧 IPC 或不安全直连。

## 验证与边界

门禁递归扫描 Preload 源码和最终编译产物，禁止 `node:crypto`、`createHmac`、设备键、真实配置和 Main-only 模块。macOS arm64 打包冒烟以临时 userData 与 loopback fixture 启动，保留 `sandbox: true`、`contextIsolation: true`、`nodeIntegration: false`，验证 Bridge 与非空 Renderer，且不创建队列、批次或快照。

本版本没有数据库迁移、生产部署或生产数据变更。回滚方式为回滚本 PR 的合并提交；正式包安装与真实 Profile 验收必须另行授权。
