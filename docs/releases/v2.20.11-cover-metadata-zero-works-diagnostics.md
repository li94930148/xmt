# XMT v2.20.11 Creator 封面来源空作品诊断

- System：`v2.20.11`

## 修复内容

唯一一次受控检查曾返回聚合 `works=0`。根因是 Python raw regex 误写为双重反斜杠，无法匹配正常 Creator HTTPS XHR。现在使用锚定正则并逐响应校验 `https` 与精确主机；相似域名、子域、用户信息和非 HTTPS 地址均不接受。

来源为空不再被汇总为成功空结果，而是以 `COVER_METADATA_SOURCE_NOT_FOUND`、固定终止原因及白名单阶段统计返回。结果不含 URL、账号、作品、Cookie、Token、HTML 或异常文本。

## 安全与回滚

功能仍仅访问内容管理页面并在内存统计；不会调用普通同步、上传、scheduler、queue、batch、snapshot、Excel 下载或业务数据库写入。未执行第二次真实检查，未安装 v2.13.6-agent。回滚时回滚本版本合并提交；没有数据库迁移。
