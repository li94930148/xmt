# XMT v2.20.13 总结归档正文显示修复

## 范围

- 修复月报、年报表单提交 snake_case 字段未被服务端读取，导致记录存在但正文为空。
- 归档接口为月报、年报统一输出 `display_content_md`；前端只使用该展示字段。
- 日报归档路径、权限模型和数据库 schema 不变。

## 数据兼容

- 新数据以 `work_summary_md` / `annual_summary_md` 为规范正文来源。
- 历史记录在规范字段没有有效内容时，按优先级读取旧 `content_md`。
- `null`、纯空白、`&nbsp;` 和空 HTML 节点会被视为无内容；正常文本和换行保持原样，以 React 文本节点安全显示。
- 生产只读检查显示 2026 年 8 月、9 月各 1 条月报在规范字段和旧字段中均无正文；这些数据不能由代码恢复或伪造。

## 验证与回滚

- 新增接口合同覆盖写入、归档、历史兼容、空正文、成员过滤和归档访问控制；既有日报权限合同继续通过。
- 无迁移，部署脚本会按既有流程进行数据库备份、Restore Drill、完整性检查和 health 验证。
- 回滚点为部署前生产 SHA；本版本无数据库结构变更，回滚不会删除或改写任何总结记录。
