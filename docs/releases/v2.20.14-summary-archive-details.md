# XMT v2.20.14 总结归档详情完善

## 范围

- 月报、年报归档列表保留摘要，增加整行点击和明确“查看详情”入口。
- 详情使用既有 `BaseModal`，月报展示工作总结、重点项目、问题与计划；年报展示年度总结、主要成果、经验不足、下一年度计划。
- 显示提交人、所属期间、提交时间与最后更新时间；长内容自然换行并在弹窗内滚动。

- 归档列表和新增的按 ID 详情接口仅允许管理员、主管访问；非法参数 400、无权限 403、记录不存在 404。
- 列表已携带完整字段时直接打开详情，避免重复请求和旧响应覆盖新选择。
- 无数据库迁移或历史数据写入。旧字段兼容仍由 v2.20.13 的服务端映射统一处理。
