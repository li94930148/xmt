# XMT v2.20.19 Creator 托管封面与作品身份收口

- System：`v2.20.19`
- Creator Agent：`v2.13.8-agent`

## 用户可见变化

作品库、驾驶舱 TOP5 和作品详情优先显示 XMT 托管封面。同一账号下规范标题与精确发布时间一致、但被 Creator Center 暴露为不同 19 位 ID 的记录合并展示；不同发布时间的同名作品继续保留。

## 安全与存储边界

Agent 只接收认证浏览器已经成功加载的图片响应字节，不导出 Cookie、Token、请求头、完整 XHR 或浏览器存储。单图上限 128 KiB、单次总量上限 4 MiB，并验证允许的 MIME、图片魔数、字节长度与 SHA-256；该总量为 12 MiB 加密传输包保留原有作品与审计数据空间。服务端通过既有加密/HMAC/nonce 同步包接收，按账号和作品 ID 幂等保存；图片读取继续要求登录态和 `creator:data:view`。

新增 `creator_cover_assets` 表，不删除已有作品、快照或分析记录。回滚代码后该表可保留，不影响旧版本读取。

## 验收边界

代码合同和本地 HTTP 权限闭环通过后，仍需发布 v2.13.8-agent、完成一次真实账号同步，再在已认证生产页面核对托管封面覆盖。旧 Agent 不会上传图片资产。
