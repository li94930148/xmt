# XMT v2.20.2 主线收口与 Android Native Auth 续期修复

- 版本：v2.20.2
- 更新时间：2026-08-27
- 升级类型：PATCH 修复
- 功能模块：Android、Auth V1、版本治理、历史观测文档

## 修复问题

- 补回原 `codex/v2-19-9-native-refresh-runtime-integration` 中尚未进入 `main` 的有效修复。
- V1 登录适配器保留服务端 `expiresIn`，Android 真实登录完成后显式调用 Native Runtime 安排 refresh。
- refresh 成功后使用新生命周期重排下一周期；JWT `exp` 仅作回退，并支持 resume、network、visibility 与延迟定时器补偿。
- 调度增加 generation guard 与 single-flight，清理后旧定时器不能重新触发。
- 新增从无 Token 到真实登录、连续两轮 refresh、恢复补偿与 cleanup 的集成合同并接入 CI。

## 数据库变化

无数据库迁移，不修改现有业务数据。

## API 变化

不新增服务端接口；客户端严格校验移动登录和 refresh 响应中的 `expiresIn`。

## 前端与 Android 变化

- 登录页在 Android 登录成功后显式绑定 Token 生命周期。
- XMT 与 Android 版本统一为 2.20.2 / 22002。
- Creator Agent 保持 2.12.1-agent，Scrapling Collector 合同不变。

## 文档收口

归档 v2.17.2 Socket 业务时段只读观察报告。该分支中的日报布局修复已经由 v2.19.3 进入主线，本次不重复迁移代码。

## 风险说明

- 影响移动端登录后的 Token 自动续期时序，需要重点回归登录、两轮 refresh、前后台恢复与网络恢复。
- 不改变 RBAC、Session concurrency、生产 API/Socket 端点、Creator Agent 上传协议或数据库结构。
- 本次仅合并代码与文档，不自动部署生产，也不启用 Mobile Auth / Mobile Socket 灰度。
