# XMT v2.20.6 Creator Agent 认证能力状态发布说明

## 范围

- System：`v2.20.6`
- Creator Agent：`v2.13.2-agent`
- 不新增数据库迁移，不改变 v1/v2 上传、AES-256-GCM、HMAC-SHA256、nonce 防重放或受管 Profile 策略。

## 根因与修复

此前 Main 将 `activeSession` 的页面存活视为 Profile 已认证的前提，并在临时登录窗口关闭时一并清空认证事实。启动快照没有重新检查受管 Profile，Renderer 又自行组合禁用条件，导致“登录状态正常 / 打开登录窗口 / 同步禁用”并存。

v2.20.6 将认证事实固定为 `unknown`、`unauthenticated`、`authenticated`、`expired`、`error`，将窗口交互固定为 `closed`、`opening`、`awaiting_confirmation`、`closing`、`error`。Main 只读下发浏览器、绑定、Token、数据库和同步状态计算出的 `canSync` 与 `loginAction`。Renderer 在首次加载、恢复和重新聚焦时重新读取该快照；`agent:sync` 会在 Main 再次 fail-closed 校验。

## 验证边界

- 已认证 Profile + 窗口关闭必须显示“重新登录”并允许同步。
- 未认证、过期、浏览器/绑定/Token/数据库未就绪均不得入队或发送 HTTP。
- 正式包仅使用 `process.resourcesPath` 的自包含 arm64 Worker；不含数据库、Profile、Cookie、Token、XLSX、日志或密钥。
- 本轮正式 UI 仅停在生产同步前状态核验；生产同步须单独授权。
