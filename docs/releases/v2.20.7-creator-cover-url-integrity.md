# XMT v2.20.7 Creator 作品封面 URL 完整性发布说明

发布日期：2026-08-31

## 范围

- System：`v2.20.7`
- Creator Agent：保持 `v2.13.2-agent`
- 无数据库迁移、无上传协议变化、无 Profile 或凭据处理变化。

## 修复

历史兼容同步曾将任意非空封面文本写入作品库，导致相对路径在浏览器中无法加载。本版统一经封面解析器校验，仅允许 HTTP(S) URL；新值为空或无效时不覆盖已有有效封面。读取历史作品时会从已经保存的 raw 数据中解析合法候选 URL。

作品库读取同时在当前抖音账号范围内按 aweme ID 生成 canonical 作品；缺少有效 aweme ID 的精确 fallback 如发生碰撞则拒绝合并。每个 canonical 作品选择一个确定性快照，不累计或混拼指标；缩略图使用最多四个合法、去重候选，前端失败时按顺序回退。

无法从已存数据恢复封面的作品保持明确占位，等待下一次正常采集补齐；系统不会伪造封面或访问额外外部资源。

## 验证

- 封面 URL 完整性合同覆盖 HTTP(S)、协议相对 URL、相对路径拒绝、raw 回退和危险 scheme 拒绝。
- TypeScript 检查、生产构建、Creator v2.10.2 合同和防重放合同通过。
