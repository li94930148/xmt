# XMT v2.20.8 本地封面来源检查

## 范围

- System：`v2.20.8`
- Creator Agent：`v2.13.3-agent`
- 无生产数据库迁移、无上传协议变更、无业务数据同步。

## 安全边界

Renderer 只能通过 `cover-metadata:inspect` 触发独立 Worker 白名单任务。任务只访问内容管理页，在内存中处理候选并返回严格白名单的聚合摘要。

任务不调用普通同步、上传器、队列、调度器、batch、快照、业务指标或官方 Excel 下载。认证、绑定、Bridge、分页或探测失败均 fail-closed。

## 图片探测

- 只允许 HTTP(S) 公网地址；拒绝凭据 URL、环回、私网、保留地址与不安全重定向。
- 最多三次重定向、并发最多两条、单请求最多十秒、有限响应字节。
- 同时验证 Content-Type 与图片魔数；不保存图片或完整 URL。
