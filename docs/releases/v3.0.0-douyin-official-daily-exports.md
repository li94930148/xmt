# v3.0.0 抖音官方双导出与逐日口径

## 目标

以抖音创作者中心官方导出作为运营中心的主要事实来源：内容管理提供最新作品累计快照，数据中心分别提供昨天、近 7 天、近 30 天的逐日表现，并由本地 Agent 后台静默采集。

## 完成内容

- Creator Agent 自动采集强制使用无头 Chromium；可见浏览器仅用于人工登录。
- 内容管理导出一次作品列表；数据中心按三个周期分别导出，四份文件不完整即拒绝同步。
- 官方日指标保留周期和文件来源，较旧采集不覆盖较新数据。
- 运营概览、趋势与日报/周报/月报读取对应官方周期；计数求和，率与时长按播放量加权。
- 负数评论等平台修正值原样保存，不清零、不伪造。

## 数据库变化

新增 migration 014：`creator_official_daily_metrics` 保存账号、日期、周期、指标、文件摘要、解析器和采集时间；`creator_ingest_files` 增加数据集类型和周期。迁移只新增结构，不删除或改写历史业务数据。

## 验证与风险

附件样本解析、四文件上传契约、迁移、幂等、最新数据门禁、加权计算、统一报告和 TypeScript 检查已通过。真实 Creator Center UI 仍可能调整文字或下载行为，首次安装后必须执行一次真实四文件同步；若任何控件或下载不符合契约，Agent 会失败关闭并保留旧的最后成功数据。
