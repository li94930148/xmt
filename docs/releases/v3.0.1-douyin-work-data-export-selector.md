# v3.0.1 抖音作品数据导出定位修复

## 修复内容

真实账号验收确认抖音数据中心同一页面有两个“导出数据”按钮。Creator Agent v2.14.0-agent 选择了页面下方的粉丝指标导出，质量门槛因“昨天”文件没有作品日指标而拒绝上传。v2.14.1-agent 改为选择“作品数据”区域中排在前面的导出按钮。

## 安全边界

本次不修改数据库结构，不删除、合并或回填历史。文件类型错误、日期行数不符合昨天、近 7 天、近 30 天时仍会失败关闭，最后一次成功数据保持不变。

## 验证

采集器全量测试、导出按钮定向回归、TypeScript 检查、生产构建和版本一致性检查通过后，安装 v2.14.1-agent 执行真实四文件同步。
