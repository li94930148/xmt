# v3.0.2 抖音作品状态标量兼容

## 背景

Creator Agent v2.14.1-agent 已真实下载作品列表及昨天、近 7 天、近 30 天三份作品数据，官方导出通过质量门槛并成功写入生产库。同期普通作品快照因抖音接口把作品状态从标量改为对象而触发 SQLite 类型保护，任务被正确标记为“部分成功”。

## 修复

- 对象形态的作品状态只从 `status`、`value`、`code`、`text`、`label`、`name` 中提取标量。
- 不认识的对象或数组按缺失值处理，不猜测、不序列化为展示状态，也不绕过 SQLite 类型保护。
- 官方四文件解析、1/7/30 天窗口、最新完整批次优先和失败关闭规则保持不变。

## 验收

- 归一化回归覆盖字符串、对象标量、未知对象和数组。
- 全量采集器、Agent、版本、TypeScript 与构建门禁通过。
- 安装 v2.14.2-agent 后执行真实小范围同步，确认任务整体成功、四文件完整、周期日数为 1/7/30，且上传队列没有新增失败。
