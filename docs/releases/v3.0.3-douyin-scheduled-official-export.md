# v3.0.3 抖音定时官方导出稳定化

## 背景

真实验收确认手动“小范围同步”能够完整下载作品列表、昨天、近 7 天、近 30 天四份官方文件并成功入库；定时器此前仍调用全量作品滚动路径，而该路径存在浏览器上下文关闭的独立风险，会在进入官方导出前中断自动任务。

## 调整

- 每日与 12 小时自动任务固定使用 `metrics_refresh`，执行与真实验收成功的小范围同步相同的官方四文件流程。
- 手动“小范围同步”保持不变；手动“开始同步”继续使用 `full_snapshot`，用于需要完整页面采集证据时人工触发。
- 四文件完整性、1/7/30 天周期日数、最新完整批次优先、加密上传与失败关闭规则均不变。

## 验收

- 调度单元测试覆盖 `manual`、`12h` 和 `daily` 三种配置。
- Collector、Agent、版本、TypeScript、构建与 CI 门禁通过。
- 安装后核对现有定时设置未被覆盖，并确认下一次自动任务走官方四文件模式。
