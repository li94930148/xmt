# v3.0.4 抖音周期指标可用性修复

## 范围与口径

- 运营概览的近 7 天、近 30 天播放与互动来自对应周期的最新官方逐日导出，按日合计；不与累计作品数相减。
- 粉丝净变化仅在期初与期末存在真实、可比的粉丝总量快照时计算。缺少基线或官方周期文件时，页面按字段说明原因，不把缺失值显示为零。
- 官方作品导入本身不包含账号粉丝总量，不能复制旧账号值作为当天观测；同一天已有真实观测时保留它。

## 数据与验收边界

- 无数据库迁移，不批量修改生产历史快照。历史快照中的旧来源可信度需要另行审计；本次只阻止新增伪观测。
- 使用官方导入契约测试确认：仅官方文件产生的当日快照粉丝字段不可用，已有同日真实粉丝值不被覆盖。
- 使用统一报告测试确认：缺少粉丝基线时粉丝增长为 `null`，官方播放仍可展示，数据完整度为部分可用。
- `npm run version:check`、`npm run check`、`npm run build`、官方导入与统一报告测试通过；页面独立渲染在 390px 和 1280px 宽度通过，无横向溢出。
- 生产端仅做只读数据聚合核对；未推送、部署或执行登录后的完整页面验收。
