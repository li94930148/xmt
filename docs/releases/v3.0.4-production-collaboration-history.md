# v3.0.4 协作编辑与版本记录修复

## 本次修复

- 普通编辑、选中文字后粘贴和自动保存都留在当前稿件版本；仅明确选择“小修”或“另开新版”时生成相应版本。
- 多人协作中的远端更新不再误触发本地旧内容保存；写入前核对正文和版本，冲突返回提示而非静默覆盖。
- 协作房间绑定具体稿件版本，旧版本不能继续向新版本提交修改。
- 内容动态只将版本历史视为旧版快照，当前保存单独记录；SQLite 的历史 UTC 时间转换为北京时间，并显示实际保存者。

## 数据与验收边界

- 无数据库结构迁移，也不会自动修订已有版本号、历史时间或丢失的正文。
- 生产稿件 110 的历史文字须依据备份及当事人草稿单独核对；不能用推测内容覆盖现稿。
- 发版前要求双账号登录和隔离稿件协作验收，以及版本、类型、构建、备份与生产健康检查。
