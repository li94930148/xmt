# v3.3.0 选题草稿、窄屏列表与编辑器写作辅助

## 目标与范围

继续实施《XMT 产品改造清单》中的选题真草稿、统一大纲编辑器、核心操作跨分辨率可见性，以及编辑器搜索替换与写作目标。不调整选题状态机、权限或生产数据。

## 已完成

- “存本机草稿”只写当前设备和账号的本地草稿；再次打开新增选题页可续写。提报成功才调用创建接口，清除对应草稿，并直达新选题详情。
- 新增选题大纲从旧编辑器切到统一 Tiptap 编辑器，继续使用 HTML 字符串，不改变 API 与数据库格式。
- 新增页的返回、预览、草稿和提报按钮在窄屏自动换行；选题列表使用响应式表格壳，横向滚动时操作列保持可见。
- 编辑器菜单和字数同步不再访问已销毁的实例，避免页面切换时偶发白屏。
- 统一 Tiptap 编辑器可查找、逐个/全部替换、切换大小写与全词匹配；查找高亮只属于视图，关闭后移除。只读模式仅可查找。
- 编辑器页脚显示当前字数、目标字数、完成进度和预计阅读时长。字数忽略空白，按 Unicode 字符计数；阅读时长按每分钟约 300 字向上估算。
- 创作详情的当前可编辑稿件支持专注写作：隐藏全局导航、资料和版本区，保留正文、简明保存状态与退出入口；按 Esc 也可退出。历史版本、只读稿件或已被新大版本取代的稿件不提供入口。
- 当前可编辑稿件支持“按大纲续写”：从选题大纲提取标题，只在正文末尾补入尚不存在的小节和空段落。重复点击不复制标题，插入可撤销。
- 创作资料搜索结果区分“已用/待用”。单选资料可“引用到正文”，将资料全文作为引用块并附上指向资料详情的“来源：资料名”；原“加入资料草稿”路径继续独立保存，不写正式正文。
- 资料草稿支持先选中片段再“引用选中片段”：选择一条来源资料后，仅当该片段可在来源原文中找到时，才将片段和来源链接写入正式正文。来源不匹配时保留选择窗口和原稿，不写入正文。
- 本轮继续统一编辑器目录、报告中心、日报、知识库、发布列表与日历中已定位的硬编码浅色表面；编辑器目录改用主题令牌，并移除对整个应用状态的订阅。
- 后续继续统一消息流、复盘列表与详情、匿名意见展示与管理中的筛选、卡片、表格及浮层表面。
- 本轮再统一全局侧栏、资料中心/详情/资源表格、日报归档与审核、复盘创建/行动详情及指标卡片的表面和输入控件令牌。
- 本轮继续收敛复盘行动表格与风险面板、日报详情抽屉和月/年报表单；复盘及日报组件扫描范围内不再发现白色半透明表面类名。
- 本轮修正公告类型浅色态（使用已定义但此前未使用的浅色语义表面），并适配公告卡片、资料搜索/旧资源管理页、通用资料类型徽标及匿名意见弹窗。
- 本轮统一全局顶部栏、命令面板快捷键、选题表格操作、404 页面与外观设置通用预览卡片的主题表面和悬停态。
- 本轮编辑器右键菜单与浮动格式栏统一使用主题玻璃表面令牌，移除浅色分支中的纯白半透明硬编码。
- 继续检查编辑器浮层时，颜色/高亮子菜单浅色底改用玻璃表面令牌；右键菜单和子菜单的浅色悬停态同时切换为主强调色前景，避免 muted 前景与主色底叠加后辨识不足。
- 后续编辑器控件检查修正浅色“首行缩进”和标题菜单已启用态（主色底配白字）、块操作菜单及批注对话框硬编码白底，并将删除批注悬停底色改为浅语义色，避免与语义文字同色叠加。
- 继续全站检查时发现富文本浮动格式栏的浅色激活按钮仍使用主色底与主色字；统一改为主色底白字，修复加粗、斜体等选区激活态的同色叠字。
- 检查登录入口确认企业版布局采用固定深色品牌背景；提升密码显隐、记住密码和登录方式文案的悬停对比，不再在悬停时降低到半透明白。
- 旧 `DashboardBento` 组件适配了明暗主题：浅色下移除深色遮罩并使用 surface/text tokens，卡片底色与说明文本跟随主题令牌，光效采用对应主题的 cyan 值；当前首页已改为“工作台”，该组件未挂载，不能将组件级适配当作首页运行态验收。
- 选题详情不再对待审核状态显示通用“推进到下一阶段”按钮；待审变更仍走审核接口，后续阶段推进仍由服务端状态机校验。
- 创作稿收到新版替代事件后仍立即锁为只读，但提醒改为编辑器顶部可操作提示，不再以全屏弹窗打断页面。
- 手机创作页不再裁切编辑器工具栏及其下拉浮层；编辑区自身继续限制横向宽度。
- 前端验收发现 Aurora 把 CSS token 字符串直接传给颜色解析器，导致控制台重复告警；适配器现按当前主题解析 `--xmt-*` token 为颜色值，颜色仍由主题令牌提供。
- 浅色主题 muted 文本令牌从 `#6B7A93` 加深至 `#5B667A`；按 WCAG 相对亮度计算，在 app 背景、主表面、次表面、抬升表面与柔和背景上对比度约为 4.98:1–5.79:1。深色主题未改。
- 移除旧 `useTheme` hook 对独立 `theme` 本地存储键和 DOM class 的写入，改为复用应用主题 store；Tailwind `theme-hover` 别名改为跟随当前主题的 elevated surface。
- React Bits Dock 导航表面不再固定暗色 slate 背景，改用主题玻璃表面令牌；Pill Nav 同步使用相同的主题材质。

## 数据与兼容边界

- 无数据库迁移，不批量更改已有选题、稿件和历史内容。
- 旧版“保存草稿”实际创建的待审选题仍是既有业务记录；不自动合并或删除，需单独人工核对。
- 本机草稿需手动保存，只在当前设备和账号可读；换设备不会同步。
- 旧编辑器兼容分支保留，历史 HTML 预览继续经过现有清洗与主题兼容层。
- 替换是当前正文的一次普通编辑事务，可撤销；不自动保存或创建新版本。正式协作稿件仍走现有 Yjs 与保存链路。
- 写作目标只存数字：有稳定稿件标识时按当前设备、账号和稿件保存在浏览器；无标识时仅在当前页面有效。目标不是正文、协作状态或服务端数据，不参与版本与审核。
- 专注写作只切换布局，不重建正文编辑器、不改写保存策略或协作房间；退出后版本操作与资料区恢复原样。
- 大纲续写通过当前正文编辑器事务写入，沿用既有自动保存与协作链路；不修改大纲本身，不新建版本。详情页通知更新不得重拉详情并覆盖尚未保存的正文。
- “已用”只表示当前正式正文含本站资料详情来源链接，从正文即时推导，不是全局资料状态；删掉来源链接后恢复“待用”。引用不新增数据库表或关系记录，普通复制/粘贴不会被误认作已用。资料标题经过 HTML 转义，服务端草稿清洗保留本站来源链接。
- 片段引用使用点击时的选中文字快照，最多 5000 字；只验证归一化空白后的直接原文包含关系，不把改写或概述冒充原话。引用文本按纯文本转义，不继承资料草稿中的任意 HTML 格式。选择无来源或改写后的片段时需手动处理，不自动猜测出处。
