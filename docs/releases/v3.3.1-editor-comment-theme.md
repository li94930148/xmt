# v3.3.1 编辑器浅色主题批注输入修正

## 目标与范围

修复统一编辑器在浅色主题下添加批注时，输入框仍使用硬编码白底和灰色占位文字的问题。本次只调整显示令牌，不改变批注交互、保存逻辑、HTML 内容或数据库。

## 修改

- 浅色主题批注输入框使用 `bg-studio-surface`、`text-studio-text-primary` 与 `placeholder:text-studio-text-muted`。
- 深色主题分支、批注确认/取消、批注数据格式均保持原样。
- Creator Agent 版本不变；无数据库迁移。

## 验证

- `npm run check`、`npx eslint src/components/editor/Editor.tsx`、`git diff --check` 通过。
- 在本机 1440×900 浅色主题中，通过“登录 → 新建选题 → 输入临时文本并选中 → 添加批注”打开输入框，再取消关闭。渲染背景为 `rgb(255, 255, 255)`（由主题 surface token 提供），正文 `rgb(15, 23, 42)`，占位文字 `rgb(91, 102, 122)`；控制台错误为 0。
- `npm run version:check` 与 `npm run build` 通过；构建仍报告已知 Silk 背景 chunk 超过 500 kB 的非阻断警告。
- 测试写入仅作用于临时隔离数据库副本；临时服务和数据库副本已清理。未在生产环境验收，未提交或部署。
