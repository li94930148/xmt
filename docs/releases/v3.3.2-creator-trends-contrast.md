# v3.3.2 趋势周期主题对比度

## 目标与范围

修复数据趋势中心周期选择按钮在浅色主题下低对比、选中背景不可见的问题。本次只调整按钮呈现，不改趋势接口、周期口径、权限或数据。

## 修改

- 选中态使用 `bg-studio-surface-soft` 与 `text-studio-cyan-contrast`，并用主题 cyan 边框指示当前项。
- 未选中态保留 muted 文本和透明边框；点击仍按原逻辑请求对应周期。
- 本轮同时回归 v3.3.1 的批注输入修正：暗色主题添加批注和编辑已有批注路径均可打开、显示已存临时文本并取消。
- Creator Agent 版本不变；无数据库迁移。

## 验证

- 浅色与暗色 1440×900 Playwright：登录后从导航打开数据趋势，点击“7 天”，选中态显示正确并触发 `period=7d` 请求。趋势响应使用临时测试响应，不是真实数据；控制台错误为 0。
- 选中文字与选中底色对比度：浅色 6.47:1，暗色 13.87:1。
- `npm run check`、`npm run version:check`、定向 ESLint、`git diff --check` 和 `npm run build` 通过。构建包含已知 Silk 背景 chunk >500 kB 的非阻断提示。
- 批注回归使用隔离数据库副本，临时文本未提交选题；测试服务和副本已清理。

## 后续

真实账号下的趋势权限与数据含义未在本轮验收。继续检查其他低对比语义色，包括灵感“有新评论”状态，以及全站剩余主题表面。未部署或提交。
