# 依赖安全审计清单

## 审计口径

- CI 的发布阻断项审计生产运行依赖：`npm audit --omit=dev --audit-level=high`。
- 安全部署在构建、版本、迁移和重启后的运行检查全部通过后执行 `npm prune --omit=dev`；`tsx` 保留在生产依赖中，因为 `start` 使用它运行 API 服务。
- 全量 `npm audit` 仍需关注开发工具依赖；不把仅限开发依赖解释为已修复或审计清零。
