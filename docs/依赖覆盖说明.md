# 依赖覆盖说明

`package.json#overrides` 只用于约束上游依赖树中的确定版本。升级或删除覆盖项前，应重新运行 `npm audit --omit=dev`、类型检查和生产构建。

| 依赖 | 固定版本 | 原因 | 退出条件 |
| --- | --- | --- | --- |
| `xcode > uuid` | `11.1.1` | 保持 macOS 打包链路使用同一 UUID 实现，避免上游子依赖漂移 | `xcode` 自身锁定兼容版本后移除 |
| `ws` | `8.21.3` | 修复 WebSocket 依赖树中的安全问题 | 所有直接依赖均带入不低于该版本后移除 |
| `ip-address` | `10.5.0` | 修复地址解析依赖的安全问题 | 上游不再解析到旧版本后移除 |
| `socket.io-parser` | `4.2.7` | 统一 Socket.IO 协议解析版本并带入安全修复 | Socket.IO 全链路升级后复核 |
| `socket.io-adapter` | `2.5.8` | 统一 Socket.IO 适配器版本并带入安全修复 | Socket.IO 全链路升级后复核 |
| `engine.io` | `6.6.9` | 修复服务端传输层依赖的安全问题 | Socket.IO 服务端不再带入旧版本后移除 |
| `engine.io-client` | `6.6.6` | 修复客户端传输层依赖的安全问题 | Socket.IO 客户端不再带入旧版本后移除 |
| `body-parser` | `1.20.6` | 修复请求体解析依赖的安全问题 | Express 不再带入旧版本后移除 |
| `qs` | `6.16.0` | 修复数组上限绕过和 `isBuffer` 拒绝服务问题 | Express 与 `body-parser` 均带入不低于该版本后移除 |

覆盖项不是常规升级入口。每项都需要保留上述动机、验证结果和可移除条件。
