# 数据复盘系统前端设计

## 当前页面

- `/retrospectives`：复盘中心列表页，包含筛选、新建入口、复盘列表和“我的复盘行动项”。
- `/retrospectives/:id`：复盘详情页，包含基础信息、指标快照、结论、日报风险联动、行动项、发布归档和导出入口。
- `/analytics`：继续作为实时数据看板保留，不与复盘中心合并。

## 结论、行动项与异步读取保护（v9.1.17 本地）

- 页面结论保存已保存基线；更新快照/行动项或刷新不会覆盖尚未保存的文字，结论保存响应也只同步其提交快照，不覆盖等待期间的新输入。
- 未保存结论需先显式保存再发布/归档；若他人发布使当前结论只读，页面保留未保存文字供复制，并经用户明确确认“使用已保存结论”恢复本地显示，不产生服务器写入。
- 行动项表格与详情的已保存结果同步，真正未保存的行内编辑继续保留；旧已保存草稿不能覆盖详情新结果。
- 列表筛选/账号变化与个人行动项读取按请求代次和归属处理，旧响应不得覆盖当前结果或错误状态。
- 两个现有复盘浏览器套件在亮暗主题 × 320/390/1440px 通过；不把以上局部保护当作全站 B8 完成。

### 返回与刷新保护（v9.1.18 本地）

- “返回列表”在结论未保存时明确确认；取消保留文字，显式放弃不写服务器。已转只读的未保存文字仍提醒先复制保留；写入期间返回按钮禁用。
- 结论未保存或写入处理中注册浏览器刷新/关闭提醒，保存成功且无新修改后解除。原生提醒实际文案由浏览器决定，不宣称会显示自定义文案。
- 390px 浏览器覆盖取消、保存后解除、显式放弃与只读文字保留。其他侧栏/后退导航和详情其他读取归属仍需后续专项核查，未宣称全站导航保护完成。
