# 选题阶段进入时间

`topics.stage_entered_at` 表示选题当前 `status` 的进入时间，格式为北京时间数据库时间。它只用于展示阶段停留时长，不参与权限判断、状态迁移决策或历史回放；系统仍以当前状态驱动工作流，不改为事件溯源。

- 普通创建选题与灵感转正式选题时记录初始阶段时间。
- 审核、标准工作流、自定义审批流及发布完成等真实状态变化，与 `status` 在同一事务写入阶段时间。
- 标题、描述、大纲、负责人等普通资料修改不会重置阶段时间。
- 迁移 025 仅新增可空字段并按 `SAFE_EXPAND` 执行。已有记录不回填；`NULL` 表示缺少可信阶段起点，不可根据时间来源不一致的 `topic_history.created_at` 或没有阶段语义的 `updated_at` 推测。
- 回滚到旧应用时可忽略新增列，不需删除字段。缺少时间的旧记录在首页显示“阶段时间待确认”。
