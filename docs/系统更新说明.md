# XMT 系统升级说明

## 当前版本

v2.20.14

### v2.20.14 · 总结归档详情完善

- 月报、年报归档增加可点击条目和“查看详情”入口，完整内容以分区方式展示。
- 支持关闭按钮、遮罩和 Esc 关闭；长内容可以滚动阅读，不影响列表排版。
- 权限范围与日报归档保持不变，不修改任何历史数据。

### v2.20.13 · 总结归档正文显示修复

- 修复月报、年报正文提交后未被保存，归档列表只显示“未填写内容”的问题。
- 归档会兼容旧字段中仍存的历史正文；真正未保存正文的历史记录不会被伪造。
- 日报归档和原有成员权限规则不变。

### v2.20.12 · Creator 封面候选 403 诊断

封面来源检查会以脱敏分类说明远端拒绝或防盗链情况，不会保存图片或上传业务数据。

- 修正 Creator HTTPS XHR 捕获的双重转义，并以结构化 scheme/host 校验拒绝相似域名和用户信息绕过。
- 来源未发现返回固定错误码和脱敏阶段结果，不再显示为成功的作品 0；不改变普通同步、上传、队列或数据库写入。

### v2.20.10 · Creator Agent Preload 沙箱兼容

- 修复 Preload 间接导入 `node:crypto` 造成的 contextBridge 初始化失败；HMAC 与设备键逻辑仅在 Main 运行。
- Preload/Renderer 使用浏览器安全白名单契约，Bridge 缺失时显示固定脱敏提示，不触发任何同步回退。

### v2.20.9 · Creator Agent 账号标识脱敏

- 主进程内部保留绑定解析，Renderer 仅使用短审计标识和范围状态确认当前绑定，不显示原始账号标识。
- `agent:get-state` 与状态推送均通过 preload 白名单投影，错误与日志不再透传原始上下文。

### v2.20.8 · Creator 本地封面来源检查

- 新增独立本地封面候选检查，不触发普通同步、上传、队列、官方 Excel 下载或服务器数据写入。
- 仅展示脱敏数量、图片可用性和有效期汇总，不展示链接、作品 ID 或登录资料。

### v2.20.7 · Creator 作品封面 URL 完整性

- 修复旧兼容同步将相对封面路径写入作品库的问题；仅保存可加载的 HTTP(S) URL。
- 历史读取会使用已有 raw 数据恢复有效封面；没有可信来源时不伪造封面。

### v2.20.6 · Creator Agent 认证与窗口状态解耦

- 已认证 Profile 不再依赖临时登录窗口，Main 统一下发 `canSync` 和登录按钮动作；Renderer 恢复或聚焦时重新拉取状态。
- 浏览器、绑定、Token 或数据库未就绪时同步保持禁用，且 Main 会在 `agent:sync` 中再次 fail-closed 校验。

### v2.20.5 · Creator Agent 登录窗口状态修复

- 登录确认仅在 Main 确认受管浏览器窗口仍存活时可用；窗口关闭或进程重启会清除临时确认状态。
- `LOGIN_WINDOW_NOT_OPEN`、未确认和未知登录状态统一映射为中文脱敏提示，不向界面泄露 Electron IPC 或驱动内部错误。
- 当前浏览器以 Main 实际解析的浏览器 / driver 为准；未选择浏览器时同步保持禁用。

### v2.20.4 · Creator Agent 本地队列 SQLite 修复

- Agent 升级到 v2.13.0-agent：队列业务载荷固定为 canonical JSON TEXT，保存与读取均校验 hash。
- 旧本地数据库首次启动会幂等创建 upload_queue；不会删除原数据、Profile、Cookie 或绑定信息。
- 新增不含凭据的运行时身份与数据库就绪保护；macOS 正式包仍未开始。

### v2.20.3 · 抖音官方导出本地安全同步

- Agent 会先在本机清洗官方 Excel，再上传标准化运营指标和必要的审计摘要；原始文件和登录信息不上传。
- 服务端会识别重复批次和未变化指标，避免播放、互动或音浪被重复累计。
- 当前验证了作品列表和收获音浪文件样本；完整页面入口覆盖仍需用户提供脱敏页面结构确认。

### v2.20.2 · 主线收口与移动认证续期修复

- Android 登录后会按服务端给出的 Token 生命周期启动自动续期，并在每次续期后重新安排下一周期。
- App 回到前台或网络恢复时会补偿检查；并发触发只执行一次 refresh，旧定时器不会重复刷新。
- XMT / Android 统一升级到 2.20.2 / 22002；Creator Agent 保持 v2.12.1-agent，无数据库迁移。
- 归档历史 Socket 生产观察报告，已合并的日报布局不重复引入。

### v2.20.1 · Creator Collector 无 UI E2E 验收

- 修复 works SQLite 非标量字段持久化，并新增官方双导出连续验收入口。

### v2.20.0 · Creator Collector Scrapling First

- 创作者数据采集改为在本机独立采集 Worker 中运行，保留用户正常扫码登录和专用浏览器资料隔离。
- 采集只同步规范化运营数据；Cookie、Token、完整请求和原始响应不会写入系统日志或上传。

### v2.19.11 · Creator Agent 上传协议安全收口

- `/data-sync` 固定拒绝非 V1 协议，保留并验证已有 timestamp、nonce、HMAC 与 AES-GCM 合同。
- 旧 `/report` 上传入口返回 410；没有数据库迁移或历史 Creator 数据删除。

### v2.19.10 · 认证与角色权限安全补充

- v2.19.10 是 v2.19.9 的安全补充版本，用于关闭代码审查发现的认证 Origin 与角色权限绕过问题。
- 登录短暂失效后的自动续期只会在精确可信的服务来源执行，避免把新的登录凭据发往伪造域名、错误端口或非加密地址。
- 角色管理会先完整检查授予范围和权限范围；不具备管理员权限的人员不能通过混合角色或修改角色权限扩大自身能力。

### v2.19.9 · 权限、编辑器与认证安全硬化

- 非管理员不能通过人员管理把自己或其他账号提升为管理员。
- 富文本预览会过滤危险脚本、事件和链接；异常协作数据不会影响其他人或服务进程。
- 禁用账号后会立即退出其活动会话并断开实时连接；登录短暂失效时优先尝试安全续期。

### v2.19.8 · Android 生产端点构建合同

- 正式 Android Build 固定注入生产 HTTPS API / Socket 地址，并把非敏感构建 manifest 打入 dist、Capacitor assets 与 APK。
- Native Production 缺失或错误 endpoint 时 fail-closed；HTTP 200 HTML 不再会被误判为 API Health 或移动认证成功。
- Web 的 same-origin `/api` 合同保持不变；生产 Mobile Auth、Socket 与 allowlist 默认不因构建修复而开启。

### v2.19.7 · Android Native Auth 自动续期修复

发布日期：2026-08-17

- 前后台恢复、网络恢复共享单飞 refresh；瞬时网络失败保留 Keystore refresh credential，终态认证失败才退出登录。

## 兼容性与范围

近期升级仅调整前端视觉、交互和版本记录展示，不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。

## 版本来源

- 工程版本以 `package.json` 为唯一来源。
- Vite 在构建时将版本注入为 `__APP_VERSION__`。
- 系统更新提示与“系统更新说明”读取 `src/data/changelog.ts`。
- “关于系统”页面读取相同的 `__APP_VERSION__`，确保代码版本、弹窗版本和文档版本一致。

## 验证

执行 `npm run check`、`npm run build`、`npm run version:check`，并在登录后验证系统更新记录按时间倒序展示 v2.16.1、v2.16.0、v2.15.4 和 v2.15.3。
