# XMT 系统升级说明

## 当前版本

v2.15.4

## XMTCard 应用补全

- Dashboard 数据卡片统一迁移至 XMTCard，并保留 AnimatedNumber 与 ProgressBar。
- Topics 顶部统计卡与核心列表容器迁移至 XMTCard，保留表格语义、筛选和权限逻辑。
- Workflow 模板卡、节点卡和流程预览迁移至 XMTCard，保留状态机与权限逻辑。
- Creator 数据指标卡迁移至 XMTCard。
- 本次不修改 API、数据库、权限、Workflow Engine、Socket.IO 或 Yjs。

## React Bits 风格 UI 体验升级

- 建立 XMT Design System，新增主题 token、AnimatedNumber、ProgressBar、XMTCard。
- 首页 Dashboard 的核心指标支持轻量数字变化、进度展示和 hover 浮动。
- EmptyState 增加微动画与更明确的行动引导；LoadingState 统一骨架屏和加载反馈。
- FormModal、ConfirmModal 增加 220ms 进入动效和现有背景模糊层；页面切换控制在 300ms 内。
- Sidebar 展开收缩加入 transform/opacity/max-height 过渡，桌面、平板、移动端保持原权限逻辑。

## 兼容性与范围

本次仅升级前端视觉与交互层，不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。

## 验证

类型检查、Lint、生产构建结果以本次升级执行记录为准。
