### v2.18.0 · React Bits 场景化视觉编排与全系统体验升级

发布日期：2026-08-12

- 建立 React Bits 官方组件、Typed Adapter、Semantic Slot 与 Page Scene 的统一视觉架构，页面视觉与业务逻辑进一步解耦。
- 首页、选题、日报、Creator、Analytics、Workflow、Editor 与 Settings / Appearance Center 完成场景化视觉升级。
- 提供岚曜极光、深空科技、丝绸创意、线性协作、极简无扰、自由搭配六套视觉方案，支持页面应用范围、动效级别、深浅主题、界面字号与高级参数。
- Appearance Center 完成 Scene Preview、配置导入导出、恢复默认、持久化与页面范围控制；高级设置默认折叠。
- 完善表单可访问名称、preset 状态与折叠语义，修复主题 select 的可访问名称问题。
- 优化 Silk 动态背景生命周期与兼容处理，动效关闭、路由切换和 reload 后不残留背景 Canvas。
- Editor 使用轻量 Scene 外壳，编辑区域保持无 WebGL 干扰；Workflow 保持 strict control 与原有业务判定不变。
- 增加关键场景浏览器回归，覆盖 Canvas 生命周期、路由切换、动效开关、配置恢复与多视口体验。

影响范围：前端视觉、Appearance Center 与自动化验证；不修改后端 API、权限、Workflow Engine、Socket.IO、Yjs 或数据库。

发布日期：2026-08-08

## 兼容性与范围

近期升级仅调整前端视觉、交互和版本记录展示，不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。

## 版本来源

- 工程版本以 `package.json` 为唯一来源。
- Vite 在构建时将版本注入为 `__APP_VERSION__`。
- 系统更新提示与“系统更新说明”读取 `src/data/changelog.ts`。
- “关于系统”页面读取相同的 `__APP_VERSION__`，确保代码版本、弹窗版本和文档版本一致。

## 验证

执行 `npm run check`、`npm run build`、`npm run version:check`，并在登录后验证系统更新记录按时间倒序展示 v2.16.1、v2.16.0、v2.15.4 和 v2.15.3。
