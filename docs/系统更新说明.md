### v2.20.15 · 依赖安全与工程化收口

- 修复 `@tiptap/*` 富文本编辑器 `mergeAttributes()` 在 `__proto__` 上把自有键变成可继承可执行 DOM 属性的中危漏洞；所有 `@tiptap/*` 包升级到 3.31.x。
- 修复 `qs` 在 express / body-parser 链路上的数组上限绕过与 `isBuffer` DoS 中危漏洞；`package.json#overrides` 将 `qs` 锁定到 6.16.0。
- 新增 HTTP 级错误脱敏拦截器回归测试：起真实应用实例、注入探针路由触发 5xx，断言页面响应里不再出现 SQL、字段名或绑定参数。任何后续改动若误删应用层出口拦截器，本测试会立刻失败。
- 新增 `api/utils/limits.ts` 统一请求体与同步包体积上限。`api/app.ts` 全局 413 文案与 `creatorSyncV291.ts` 同步包 413 文案均改为引用同一常量，再不会出现"12MB"与"16MB"两种提示并存。

- 清理 `api/services/creatorDataCenter.ts` 中长期未被引用的 `acceptCreatorDataSync` 死代码副本，避免与 `creatorSyncV291.ts` 同名实现长期并存导致后续改错。
- 成就进度接口按 `condition_type`（`login_streak` 额外按时间窗）聚合缓存查询，成就数量增加时不会再退化成逐条 `COUNT(*)`。
- 新增 `deploy/linux/HTTPS_REQUIRED.md`，明确 `upgrade-insecure-requests` CSP 指令要求 XMT 必须部署在 HTTPS 站点之后；`docs/上线前检查清单.md` 同步补充对应章节。

无数据库迁移、未变更对外 API 行为；`package-lock.json` 同步更新后请运行 `npm ci` 刷新本地依赖。
