# XMT 系统升级说明

## 当前版本

v2.16.1

## 首页驾驶舱视觉增强

- Home 第一屏升级为“内容生产驾驶舱”品牌 Hero，融合 Aurora 动态背景、平台名称、核心指标与业务入口。
- MagicBento 使用非对称布局，以内容生产指数为主视觉大卡，并展示今日任务、新增选题、待审核、发布数据、播放表现和 AI 能力入口。
- 首页关键数据、趋势与卡片使用 AnimatedContent 进入动画，并启用 Spotlight、粒子、倾斜、磁吸和点击反馈。
- WebGL 不可用或用户启用减少动态效果时自动使用静态渐变降级。
- 保持 V2.16.0 已接入的 Aurora、MagicBento、AnimatedContent、SpotlightCard 和 ProfileCard，不修改业务数据逻辑。

## 兼容性

本次仅增强 Home 前端视觉与交互，不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。

- Dashboard 数据卡片统一迁移至 XMTCard，并保留 AnimatedNumber 与 ProgressBar。

- Workflow 模板卡、节点卡和流程预览迁移至 XMTCard，保留状态机与权限逻辑。
- Creator 数据指标卡迁移至 XMTCard。
- 本次不修改 API、数据库、权限、Workflow Engine、Socket.IO 或 Yjs。

## React Bits 原生体验升级

- 在现有 XMT Design System 基础上，正式接入 React Bits 官方 TypeScript + Tailwind 组件源码。
- Login 使用 Aurora 动态背景，并在 WebGL 不可用时自动降级为静态渐变背景。
- Home 驾驶舱使用 MagicBento，Dashboard 数据展示使用 AnimatedContent。
- Topics 的重点选题使用 SpotlightCard，普通选题列表保持原有高效展示方式。
- Creator Dashboard 使用 ProfileCard 展示真实创作者账号与内容数据。
- React Bits 官方组件统一放置于 `src/components/reactbits`，业务适配统一放置于 `src/components/xmt-ui`。

## 兼容性与范围

本次仅升级前端视觉与交互层，不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。React 18、TypeScript 5.8、Tailwind CSS 3.4 与 Vite 6 保持兼容。
