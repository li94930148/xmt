# XMT 系统升级说明

## 当前版本

v2.16.0

## React Bits 原生体验升级

- 在现有 XMT Design System 基础上，正式接入 React Bits 官方 TypeScript + Tailwind 组件源码。
- Login 使用 Aurora 动态背景，并在 WebGL 不可用时自动降级为静态渐变背景。
- Home 驾驶舱使用 MagicBento，Dashboard 数据展示使用 AnimatedContent。
- Topics 的重点选题使用 SpotlightCard，普通选题列表保持原有高效展示方式。
- Creator Dashboard 使用 ProfileCard 展示真实创作者账号与内容数据。
- React Bits 官方组件统一放置于 `src/components/reactbits`，业务适配统一放置于 `src/components/xmt-ui`。

## 兼容性与范围

本次仅升级前端视觉与交互层，不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。React 18、TypeScript 5.8、Tailwind CSS 3.4 与 Vite 6 保持兼容。

## 验证

已执行类型检查、生产构建、版本一致性检查及桌面端与 390×844 移动端浏览器验收。
