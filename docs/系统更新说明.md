# XMT 系统升级说明

## 当前版本 v9.4.2

移动工作区的本地验收连接已修复，检查首页加载提示时不会再被测试环境的重复重连干扰。产品页面、业务数据、接口和权限均未变化；Android 同步至 9.4.2 / 90402，GitHub CI 生成了 debug 验收 APK artifact，但未发布 Android 安装包。实际语音播报仍待进一步核实，详见 `docs/UPGRADE_PROGRESS.md`。

## 历史版本 v9.4.1

通知设置保存遇到网络中断或服务端异常时，系统会先读取服务器当前设置确认结果，不会自动重复提交。若服务器与页面草稿不同，系统会保留草稿并暂停继续编辑，让你选择载入服务器设置或明确确认覆盖；如果暂时无法核实，也会保留草稿并只提供重新核实。桌面和手机通知设置采用一致的处理方式。没有权限、数据库或真实业务数据变更。验证结果和浏览器检查范围见 `docs/UPGRADE_PROGRESS.md`；Android 仅同步 9.4.1 / 90401 版本元数据，未构建 APK。

## 历史版本 v9.4.0

生产依赖已更新到安全版本，生产依赖安全审计为零漏洞；完整依赖树保留 3 项仅影响 Tailwind 3/PostCSS 开发工具链的中危提示，自动修复需要 Tailwind 主版本升级。合并发布包含 SAFE_EXPAND 迁移 032–065，全部在隔离 SQLite 验证，生产应用受部署备份和恢复演练门禁保护。

备份创建遇到网络中断或页面刷新时，会先读取原请求的状态；如果备份已创建，页面恢复成功结果而不再生成第二份。只有服务器明确查不到时，才允许用户用原编号确认重试。核实接口使用已有备份权限且不缓存，原有客户端仍可按原方式创建备份。内容洞察的协作文档选择框补上辅助名称，手机表格可横向滚动查看“判断”列。团队日报首读期间会向辅助技术播报加载状态，只有请求成功并返回空列表后才显示“暂无团队日报”。官方周期文件缺失或无效时，日报/周报/月报发布数都按北京时间包含报告当天，分别统计 1/7/30 天；有效官方日报仍采用平台“昨天”文件。类型检查、版本一致性、全仓 lint 和生产构建通过；Chrome DevTools MCP 手工检查通过，仓库自动浏览器套件因 macOS Chromium 权限错误未进入断言，Playwright MCP 返回 `Transport closed`。本地隔离回归未访问真实业务数据库或数据。Android 仅同步 9.4.0 / 90400 元数据，未构建 APK。

## 兼容性与范围

近期升级仅调整前端视觉、交互和版本记录展示，不修改后端 API、数据库、权限系统、Workflow Engine、Socket.IO、Yjs 或 Creator Agent。

## 版本来源

- 工程版本以 `package.json` 为唯一来源。
- Vite 在构建时将版本注入为 `__APP_VERSION__`。
- 系统更新提示与“系统更新说明”读取 `src/data/changelog.ts`。
- “关于系统”页面读取相同的 `__APP_VERSION__`，确保代码版本、弹窗版本和文档版本一致。

## 验证

执行 `npm run check`、`npm run build`、`npm run version:check`，并在登录后验证系统更新记录按时间倒序展示 v2.16.1、v2.16.0、v2.15.4 和 v2.15.3。
